# Round 53 — 아이템의 파랑 뒤 격자 선, 그림자의 초록은 한 덩어리 (목업 → 판정 → 구현)

목업 뒤 사용자의 판정으로 구현했다(아래 "판정"·"구현"·"검증"). 호출 없음. 목업은 `mock_grid_lines.py`가 오늘의 스크린샷(`game/`, `20261010-r52b`) 위에 그렸다.
칸 50·사이 2라 선의 자리를 알므로, 사이의 파랑(또는 선)만 다시 칠하고 그 위의 아이콘은 그대로 둔다.

## 지시

2026-10-10 사용자(플레이 피드백): "용병 아이템창 파란색 배경있어도 뒤에 격자 구분선은 유지. / 아이템 드래그 시 인벤에 초록 배경은 격자 구분없이 나오게 / 목업 제공. 승인 후 구현".

## 지금

- **파랑(아이템의 바탕)**: 아이템이 덮는 칸들을 한 장의 파랑이 덮어, 그 안의 칸 사이 선이 보이지 않는다(`ItemSlotView`의 바탕 한 장. 아래 칸은 숨김).
  든 아이템의 밝은 파랑, 밀려날 아이템의 어두운 금빛도 같다. 노드 맵·야영지 정비·이긴 뒤의 보드, 인벤토리 창, 상점·전리품 타일의 조각이 모두 이 조각이다.
- **초록(놓일 자리의 그림자)**: 칸마다 따로 칠해 칸 사이의 회색 선이 그대로 보인다(`GridBoardView`·`InventoryGridView`의 `ShowGhost`). 놓이지 않는 자리의 빨강도 같다.
- 전투 중의 보드는 파랑이 없고 아이템 뒤로 선이 보인다(바뀌지 않음).

  (밀려날 아이템의 금빛 조각은 그림자 아래에서 그대로 보인다).

## 구현

- 바탕의 색: 지금 화면을 재어 보니 든 것이 없을 때 인벤토리 조각(31,38,84)과 보드 조각(28,36,78, 보드 패널의 어둠이 덮음)은 거의 같았다. 목업과 스크린샷에서 밝게 보인 인벤토리의 파랑(53,71,147)은
  **손에 든 아이템의 밝은 남색**이고 보드에서 든 아이템도 같다. 다만 Round 49의 남색은 비치는 색(82%)이라 아래가 다르면 색이 달랐다(상점 타일은 아래가 검어 (18,28,74)).
  → 남색 셋(`GridPiece`·`GridPiecePicked`·`GridPieceDisplaced`)을 **불투명**으로, 비치던 색이 우물의 회색(`GridSquareLine`) 위에서 내던 색 그대로 바꿨다(선형 색 공간에서 계산: `#1F2654`·`#364693`·`#5C4F22`).
  보드의 색은 그대로이고, 인벤토리·타일이 어디서나 같은 남색이 된다. 든 것의 밝은 남색은 보드와 같은 규칙이라 그대로 두었다.
- 조각(`ItemSlotView`): 바탕을 칸마다 그린다(`_ground`: 가방 타일의 `SquareGrid`와 같은 그림 없는 칸, 놓인 모양대로 `Placement.WidthOf/HeightOf`). 조각의 바닥(`_frame`)은 `GridSquareLine` 회색이라 칸 사이가 어디서나 회색 선이다(타일에서도).
  `Ground`는 칸의 색, 새 `GroundSquares`(칸 수). Builder `BuildItemSlot`에 `Ground` 층.
- 그림자(`GridBoardView`·`InventoryGridView`): 칸마다의 칠 대신 틀(격자) 안의 칸을 덮는 **한 장**(`_ghostFill`, 비치는 45% 그대로), 그 아래 칸 층에 칸의 검정 한 장(`_ghostFloor`)을 깔아 비치는 칠 아래로 사이의 회색이 보이지 않는다.
  밀려날 조각·합칠 조각은 칸 층 위라 그림자 아래에서 보인다(그 조각의 칸 사이 선도). 새 `GhostBlock`(Test용).
- 문서: Design/10 §5(【확정】 Round 53), Architecture/12("조각", "손"의 그림자, 인벤토리 창, 스크린샷).
- Test: PlayMode — 보드 조각의 칸 수(`GroundSquares`), 인벤토리 조각이 보드의 남색·불투명·칸 수, 보드와 인벤토리의 그림자가 한 장(`GhostBlock`의 폭 = 모양의 폭). 스크린샷 `_49_map_inventory_open`(든 것 없는 인벤토리), `_50_map_inventory_ghost`(인벤토리 위의 그림자). 상점 Test에 타일 조각의 남색과 칸 수.
