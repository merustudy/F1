# Round 13 — UI 꾸미기 (야영지 장비) — 구현됨

사용자 지시 (2026-10-04): "UI도 개선 가능한가? 지금 너무 심심해. 유사 유명 게임들을 검토하여 이미지 생성이 필요하다면 생성하여 UI 꾸미기. 우선 목업 이미지 제공. 내 승인 후 구현."

B의 봉인 배지와 C의 양피지 지도는 A에 얹을 수 있다(목업의 노드 맵이 그렇다).

`mock/` 소재로 돌렸다(살아 있는 소재는 건드리지 않았다): `ui_frame` `table_planks`(264x192, 결을 남김), `ui_piece` `sign`(900x150), `ui_icon` `potion_heal`(96x96). 산출물은 `output/ui_*/mock_*`(gitignore)이고 `samples/`에 복사했다.
간판은 밧줄 고리 때문에 판이 작게 맞춰진다(`glyph` 맞추기가 조각 전체를 84%에 넣는다). 구현 때는 간판을 `ui_piece`로 두되 Size를 판 기준으로 정하거나 고리를 따로 그린다.

## A안의 하단 패널: 가방·칸·아이콘이 판자와 구별되게 (사용자 피드백 2026-10-04)

사용자: "A안이 마음에 드는데, 하단 UI 패널에서 가방과 일부 이미지 색상이 비슷해서 구별이 잘 안 가. 개선 가능하다면 개선, 아니면 다른 UI 방식(하단 패널을 바꿔도 됨)."
원인: 판자(어두운 갈색), 가죽 가방(어두운 갈색), 쇠 칸(아주 어두운 갈색), 아이콘(갈색·쇠)이 모두 한 색 계열이라 단이 없다. 칸의 재질이나 가방의 색, 또는 패널 바탕을 바꿔 **두 단 이상의 대비**를 만든다.
목업 `mock-A-panels.png`(패널만 다섯 줄: 지금의 A, A1~A4)와 전체 화면 `mock-A1-navy-bag.png`, `mock-A2-paper.png`, `mock-A3-tool-roll.png`, `mock-A4-felt-table.png`.

| 안 | 무엇 | 대비의 단 | 구현 | 비용 |
|---|---|---|---|---|
| A1 남색 모직 가방 | 가죽 가방을 남색 모직(바느질 테)으로. 칸은 지금의 쇠 칸 그대로 | 판자 갈색 → 가방 남색 → 칸 어두운 쇠 → 아이콘 | `ui_variant.csv`의 `bag` 행에 Fill(남색)만. 틀 재생성 없음 | 0회 |
| A2 양피지 목록 | 유닛마다 핀으로 꽂은 크림색 양피지, 칸은 잉크로 그린 상자, 아이콘은 종이 위에 | 판자 → 크림 종이 → 잉크 상자 → 아이콘 (가장 밝다) | 종이 틀 1장 생성 + 칸 틀의 색 변형(크림, 잉크 테) | 1회 |
| **A3 캔버스 공구 말이 (권장)** | 유닛마다 캔버스 공구 말이(위에 가죽 끈과 놋쇠 버클)를 펼쳐 놓고, 칸은 바느질한 주머니. 아이콘은 밝은 캔버스 위에 | 판자 어두운 갈색 → 크림 캔버스 → 주머니(진한 테) → 갈색·쇠 아이콘. 쿨다운의 놋쇠 채움과 고른 칸의 놋쇠도 캔버스 위에서 읽힌다 | 말이 틀 1장 생성(`ui_frame`, 끈은 위 띠에) + 칸 틀의 색 변형(캔버스색) | 1회 |
| A4 남색 펠트 탁자 | 패널의 바탕을 나무 테가 둘린 남색 펠트로. 가방·칸은 지금 그대로 | 펠트 남색 → 가죽 가방 갈색 → 칸 → 아이콘 (지금 화면의 남색에 가장 가깝다) | 펠트 탁자 틀 1장 생성(또는 판자 틀의 안쪽을 남색으로 tint) | 0~1회 |

권장 A3. 이유: ① 세 단의 대비가 가장 뚜렷하고 아이콘(갈색·쇠)이 밝은 캔버스 위에서 가장 잘 읽힌다 ② "용병의 무기 말이"라 야영지 장비 테마에 맞는다 ③ 틀 하나와 색 변형으로 끝나 A의 다른 조각과 같은 길이다.
A1은 비용 없는 최소 변경(가방 색만), A2는 A3와 비슷하되 종이라 "장비" 느낌이 덜하다, A4는 판자를 가장자리로만 남겨 A의 나무 느낌이 줄어든다.
세부(권고안): 적의 말이도 같은 캔버스색(편은 명패가 말한다. 녹빛으로 물들이는 것은 선택지), 버클은 틀의 위 띠 가운데라 9-slice 가로 늘임에 걸리므로 틀의 Size를 화면 폭(188)에 맞춰 생성한다.
