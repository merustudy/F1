## 지금

- 아이템의 분류(`ItemData.Category`)는 `Weapon`과 `Support`다(Design/02 §4 【확정】 (일괄)). 규칙에서 쓰는 곳은 하나다: **무기 패시브(무기 피해 +%, 무기 적중 시 화상)는 `Weapon`의 피해 효과에만** 걸린다(`BattleEngine.Activate`: `effect.Kind == Damage && Category == Weapon`).
- 화면에서는 `Weapon`이 발동하면 주인이 적 쪽으로 돌진한다(`BattlePresenter.PlayActivation`). `Support`는 칸만 번쩍이고 주인은 움직이지 않는다. 아이템 설명에 "무기"/"지원"이 적힌다(`UiText`).
- 직업의 기본 무기(`JobData.WeaponItemId`)에서 주교의 것이 치유의 지팡이다. 데이터는 이미 그것을 주교의 "무기 칸"에 둔다.

## 분류 — 치유의 지팡이를 무기로

| 분류 | 아이템 | 발동할 때 |
|---|---|---|
| 무기 | 소드, 롱소드, 대도끼, 메이스, 화염 지팡이, **치유의 지팡이(지원 → 무기)**, 단검, 장궁, 창, 미늘창 / 적: 물어뜯기, 녹슨 칼, 조잡한 활, 감독관의 망치, 감독관의 포효 | 용병은 공격 자세 + 돌진, 적은 돌진(자세 없음) |
| 지원 | 버클러, 수호 부적, 약초 주머니, 불씨 플라스크 / 적: 저주의 침, 치유 주문 | 아래 "지원 아이템의 움직임" |

- 권장: 치유의 지팡이의 `Category`를 `Weapon`으로 바꾼다(데이터 한 칸). **전투 규칙은 바뀌지 않는다**: 무기 패시브는 피해 효과에만 걸리는데 치유의 지팡이는 회복 효과뿐이다. 바뀌는 것은 발동할 때의 움직임과 아이템 설명의 "지원" → "무기"다.
  구현 때 같은 시드로 시뮬을 돌려 결과가 같음을 확인한다(데이터 변경의 절차). Design/02 §4에 적는다.
- 버클러(방패)는 손에 들지만 **지원으로 둔다**(권장): 공격 자세는 무기를 휘두르는 그림이라 방패를 올리는 순간과 맞지 않는다.
- 포션은 아이템이 아니라 플레이어가 벨트에서 쓰는 것이다. 지금처럼 대상에 효과(숫자, 번쩍임)만 보이고 유닛은 움직이지 않는다(권장).

## 두 번째 검토 — 분류 다섯 (승인됨)

### 분류를 어디에 두나

- **지금의 `ItemData.Category` 하나를 다섯 값으로 넓힌다**(권장): `Weapon`(무기 장비), `Armor`(방어 장비), `Attack`(공격 아이템), `Support`(지원 아이템: 회복·버프), `Other`(기타 아이템).
  열을 하나 더 두면 "무기인가"를 두 열이 함께 말해 어긋날 수 있다. 한 열이면 규칙과 화면이 같은 값을 본다.
- **전투 규칙은 그대로다**: 엔진은 분류를 "무기 피해/무기 적중 패시브는 `Weapon`의 피해 효과에만"에만 쓴다. 무기는 그대로 무기이고, 새로 무기가 되는 치유의 지팡이는 피해 효과가 없다. 나머지는 지금도 무기가 아니다.
  구현 때 같은 시드로 시뮬을 돌려 결과가 같음을 확인한다.
- `Support`는 뜻이 좁아진다(지금은 "무기가 아닌 것 전부", 앞으로는 "회복·버프"). 기획(Design/02 §4의 【확정】 (일괄) "분류는 `Weapon`과 `Support`")을 먼저 고친다.

### 아이템마다 (지금의 스물한 개)

| 분류 | 아이템 | 발동할 때의 움직임 |
|---|---|---|
| 무기 장비 `Weapon` | 소드, 롱소드, 대도끼, 메이스, 화염 지팡이, **치유의 지팡이**(지원 → 무기), 단검, 장궁, 창, 미늘창 / 적: 물어뜯기, 녹슨 칼, 조잡한 활, 감독관의 망치, 감독관의 포효 | 용병: 공격 자세 + 돌진. 적: 돌진(적은 자세 그림이 없다) |
| 방어 장비 `Armor` | **버클러**(지원 → 방어) | A 돌진(자세 없이) |
| 공격 아이템 `Attack` | **불씨 플라스크**(적 앞에 화상) / 적: **저주의 침**(지원 → 공격) | A 돌진 |
| 지원 아이템 `Support` | 수호 부적(동료에 방어), 약초 주머니(자기 회복) / 적: 치유 주문 | C 맥동과 빛 |
| 기타 아이템 `Other` | (지금은 없다) | A 돌진 |

- 적의 물어뜯기·포효는 손에 든 장비가 아니지만 무기로 둔다(권장): 적은 자세 그림이 없어 무기든 공격 아이템이든 돌진으로 같고, 무기로 두면 데이터와 규칙이 바뀌지 않는다.
- 피격 자세(맞아서 밀릴 때)는 분류와 상관없이 그대로다.
