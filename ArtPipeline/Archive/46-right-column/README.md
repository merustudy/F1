## 지시

2026-10-08 사용자: "1. 물약칸은 전투 위치와 같은 위치로 변경 / 2. 지도, 상점 및 보상의 아이템 선택하는 칸의 세로 길이를 더 넓게 /
3. 설명 및 인벤 버튼 있는 패널의 세로 길이를 절반으로 축소. 위 사안을 반영해 다시 목업 제공".

읽은 것(해석. 틀리면 판정에서 고친다):

  보드의 아이템 칸(왼쪽 아래 "빈 칸")을 키우라는 뜻이었다면 이 목업은 다시 만든다.
- 3 = 보드 판의 오른쪽 절반에 있는 어두운 판(제목·안내·설명 줄과 인벤토리 버튼)의 높이를 436에서 218로 줄인다.

## 권장

- **A**: 왼쪽은 무대와 보드, 오른쪽은 고르는 판과 명령 판으로 나뉘어 겹치는 데가 없다. 지도에서 전투로 넘어가면 보드 판이 전체 폭으로 바뀌지만 화면이 바뀌는 순간이라 튀지 않는다.
- **S1**: 판이 높아진 만큼 네 물건을 한눈에 비교한다(Round 42 카드를 누를 필요가 없다). 카드가 패널을 덮던 일(지금의 D)이 없어진다. 고르고 칸에 놓아 사는 조작(Round 44 ㄴ)은 그대로다.
- **L2**: 상점과 같은 타일이라 "고르고 칸에 놓는다"가 한 모양이 된다. 18단계에서 【검토】로 남긴 아이콘 카드가 이것으로 풀린다.
