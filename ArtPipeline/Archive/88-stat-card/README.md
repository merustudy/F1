## 화면에서 바뀌는 것 (41단계에 구현, A안)

- 스탯 이름: **지혜**(`Stat.Wis`) — 막사 줄·역마차 후보·파티 팝업·카드의 꼬리.
- 카드의 사실 줄: **쿨다운은 주인의 초**(`StatRules.CooldownPercent`·`CooldownMs`; 주인이 없거나 축이 없으면 데이터의 초, 색 없음). 물리의 **명중** 줄은 그대로(민첩으로 셈). 마법 무기·공격 아이템은 **"언제나 명중"**(`Item.AlwaysHits`). **치명타** 줄은 학파의 스탯(물리 민첩, 마법 지혜)으로 셈.
- 바뀌지 않는 것: 카드의 틀·자리·분류·크기·효과 줄·피로 줄·값.

## 4차 (2026-10-20 사용자 "소수점 둘째 자리에서 반올림하는 걸로 반영")

- 3차의 정수 대신 **소수 첫째 자리까지, 둘째 자리에서 반올림**: 쿨다운 2.9초·1.5초·3.5초·6.0초, 치명타·명중 %도 소수 하나까지(지금 데이터는 정수). 모습은 `mock-cards-2.png`의 C 열 그대로다(그 그림의 수치가 이 규칙). 효과 값(피해 1-3, 보호막 1)은 전부터 정수이고 바꾸지 않았다.
- 구현: `UiText.RoundedSeconds`(반올림; `Seconds`는 버림이라 시계·로그의 시각용으로 남음), `UiText.Percent`를 소수 하나(둘째 자리에서 반올림)로 — 사용자 "보여지는 화면에서": 카드와 전투 로그·자막의 명중·치명타 %가 같은 규칙.
