# Round 37 — 발키리의 붕괴(고통)·각성 초상 시험 — 판정 대기

사용자 지시 (2026-10-06, Round 36의 판정과 함께): **"발키리로 붕괴, 각성에 해당되는 테스트 이미지 생성"**. 연출 "B"(무대를 가로지르는 띠)에 "붕괴, 각성에 해당하는 이미지 생성 예정"이라 적었으므로,
띠의 글 왼쪽에 비워 둔 그림 자리(`BannerArt`. Architecture/12 "연출")에 들어갈 그림의 시험이다. 다키스트 던전의 고통·각성 알림이 영웅의 **초상**을 보이는 방식을 따라 가슴 위의 초상으로 그렸다.

## 규칙

1. **기준 그림** = 발키리의 확정 원본(`../20-serious-face/approved/character/valkyrie.raw.png`)을 그대로 붙인다(`--reference`. 뒤집지 않는다).
2. **시험 문서** `STYLE_RUNTIME-state.md`: §1·§2는 지금 문서의 것(§2 끝에 Round 23의 금지와, 초상이 하지 말 것 — 전신·다리·발, 빛·후광·광선·어두운 기운·연기, 눈물·피·상처, 다른 머리 모양 — 을 더함),
   §3 기준 그림 규칙과 §4 구도는 Round 23의 자세 규칙을 "같은 인물의 가슴 위 초상. 표정, 머리와 어깨의 자세, 손, 색의 기분만 바꾼다"로 고친 것.
   꼬리 문장은 `--tail "Draw this one character as a bust, from the top of the head to the chest."`(타입 `character`의 꼬리 "full body"를 시험에서만 바꾼다. 이번에 `gen_image.py`에 더한 옵션).
3. **소재** (`afflicted.csv`, `virtue.csv`. Key는 둘 다 `valkyrie`라 파일을 나눴다): 정체 목록(Round 23의 것에서 가슴 위에 보이는 것만) + 상태.
   - 붕괴(고통): 어깨를 움츠리고 머리를 어깨 사이로 당겨 살짝 기울임, 양손으로 도끼 자루를 가슴에 끌어안아 자루 윗부분과 날의 아래 모서리만 보임. 표정: 눈을 크게 뜨고 작은 눈동자가 오른쪽의 적을 향함, 눈썹을 치켜 모음, 입을 벌리고 이를 악문 떨리는 찡그림, 관자놀이에 식은땀 한 방울. 머리카락이 이마 위로 늘어짐.
     전체를 깊은 그늘에 선 듯 어둡고 탁한 자기 색으로, 얼굴 윗부분에 딱딱한 어두운 톤 하나. 피·상처·눈물 없음.
   - 각성: 턱을 들고 머리를 높이, 어깨를 펴고 뒤로, 한 손으로 도끼 자루를 어깨 옆에 세워 자루 윗부분과 날 아랫부분이 어깨 뒤로 보임. 표정: 차갑고 사나운 결의 — 눈을 가늘게 뜨고 눈동자는 오른쪽의 적에 고정, 눈썹은 수평으로 내림, 입은 굳게 다문 직선(웃음 없음). 머리카락이 바람에 뒤로 날림.
     전체를 따뜻하고 밝은 자기 색으로, 머리·어깨·털 가장자리의 윗선에 딱딱한 연한 금빛 톤 하나(빛의 테). 글로우·광선·후광 없음.
4. **상한**: 이 라운드 4회. **쓴 것 3회**(항목당 한 번, 붕괴는 판정 뒤 재생성 1회). 1024x1024 `medium`, 약 $0.09. 누계 약 $5.49 / $10 (Round 38의 효과 조각은 그 README).
5. 후처리: 전신 맞추기(`figure`)는 초상에 맞지 않아 쓰지 않고 원본(`output/character/valkyrie_afflicted.raw.png`, `valkyrie_virtue.raw.png`)을 본다. 띠에 넣는 크기와 자르기는 판정 뒤에 정한다(아래).

```text
.venv/bin/python ArtPipeline/tools/gen_image.py --type character --key valkyrie --name valkyrie_<afflicted|virtue> \
  --style ArtPipeline/Archive/37-valkyrie-states/STYLE_RUNTIME-state.md --roster ArtPipeline/Archive/37-valkyrie-states/<afflicted|virtue>.csv \
  --reference ArtPipeline/Archive/20-serious-face/approved/character/valkyrie.raw.png \
  --tail "Draw this one character as a bust, from the top of the head to the chest."
.venv/bin/python ArtPipeline/Archive/37-valkyrie-states/make_review.py [--game <ko_38_battle_breakdown.png>]   # review-busts.png, review-game.png
```

## 결과 (호출 2회, 약 $0.06)

- 둘 다 같은 인물(얼굴, 땋은 머리, 걸쇠와 끈, 레이스 상의, 털 소매, 도끼)이고 가슴 위에서 잘렸다. 표정은 소재대로다: 붕괴는 치켜 모은 눈썹·벌린 입과 악문 이·식은땀, 각성은 가늘게 뜬 눈·내린 눈썹·다문 입.
- 색의 기분은 약하다: 붕괴는 조금 어둡고 탁해졌고(얼굴 윗부분의 어두운 톤은 희미), 각성은 조금 따뜻해졌으나 금빛 테는 거의 없다. 각성의 왼쪽 머리카락 끝에 작은 흰 불꽃 하나가 남았다(§2의 "glow" 금지가 다 막지 못했다. 로컬에서 지울 수 있다. 호출 없음).
- 리뷰 시트 `review-busts.png`: 위에 확정 원본·붕괴·각성을 같은 높이로, 아래에 전투의 띠(두 색)에 그림 자리의 세 크기(64 띠 안 / 96·120 띠 위아래로 걸침) × 둘(전신 초상 / 머리만)을 글 왼쪽에 놓은 것.
  `review-game.png`: 같은 자리를 실제 붕괴 스크린샷(`ko_38_battle_breakdown.png`)의 띠 위에.

## 판정할 것

1. 두 초상이 발키리로 보이고 상태가 읽히는가. 색의 기분(어둡게 / 따뜻하게)을 더 세게 할지(소재 교체 → 재생성 1회씩).
2. 띠의 그림 자리: 크기(64 안 / 96 걸침 / 120 걸침)와 자르기(전신 초상 / 머리만). **권장: 96 걸침 · 머리만** — 띠(84)에 64는 얼굴이 안 읽히고, 전신 초상은 가로로 넓어 자리를 많이 차지한다. 머리만 96이 다키스트 던전의 초상 크기와 비슷하게 읽힌다.
3. 확정되면 나머지 용병 다섯도 같은 규칙으로(붕괴·각성 각 1회, 10회, 약 $0.3). 고통 셋(공포·절망·무모)을 한 그림으로 쓸지, 고통마다 다른 표정으로 그릴지(권장: 한 그림. 상태의 이름이 글로 있다).
4. 띠에 넣는 방법: 띠의 `BannerArt`(64 자리)를 판정한 크기로 바꾸고, `UiArt`에 조각을 등록해 `ExpeditionArt`가 용병별로 읽는다(Architecture/13 "Unity 배선"). 쓰러짐(200)의 띠에는 그림 없음(권장: 붕괴 초상을 그대로 쓴다).
