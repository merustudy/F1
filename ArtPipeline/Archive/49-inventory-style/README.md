## 지시

2026-10-09 사용자: "인벤토리 ui 스타일이 마음에 안들어. 인벤토리 ui 스타일 관련 아래 수행. 현재 ui 스타일과 무관하게 1. 디아블로 2 ui 스타일 차용 2. 백팩 배틀즈 ui 스타일 차용 3. 기타 유명 게임 조사 후 네 최선의 ui스타일 차용. 목업 이미지 제공해줘".

읽은 것(해석. 틀리면 판정에서 고친다):

- "인벤토리 UI"는 아이템을 다루는 네 곳으로 읽었다: **용병의 보드**(가방과 그 칸, 아이템 조각), **인벤토리 창**(지금은 목록 팝업), **아이템 카드**(우클릭 카드와 설명 줄), **놓을 때의 표시**(그림자: 맞음·하나와 겹침·둘과 겹침, 가방을 든 동안의 틀).
- "현재 스타일과 무관하게"는 재질·색·표시를 새로 정하라는 뜻으로 읽었다. 자리와 크기(칸 50·사이 2, 틀 3×8, 패널의 자리), 규칙(놓기·돌리기·인벤토리 넓이 30)은 그대로 두었다.
- 다시 그린 것은 보드 패널, 인벤토리 창, 카드, 패널의 설명 줄이다. 위의 용병, 헤더, 오른쪽 아래 버튼은 지금 그대로다.
