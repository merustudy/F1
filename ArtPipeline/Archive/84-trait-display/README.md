## 판정할 것 (권장)

1. 아이콘 테의 색: **안 1** — 줄을 훑을 때 좋은지 나쁜지가 먼저 읽힌다. 타고난/얻은은 툴팁의 첫 줄이 말한다.
2. 막사 줄: **안 A**(아이콘 + 이름) — 아이콘 그림이 생기기 전(Placeholder)에도 읽힌다.
3. 넘칠 때: **줄에 들어가는 만큼 + "+N"**, "+N"에 마우스를 올리면 나머지를 툴팁에.
4. 직업 특성의 이름: **짧은 이름 다섯을 새로 붙인다** — 제안 **선봉**(전사)·**광기**(바이킹)·**급소**(방랑자)·**후방 영창**(마법사)·**축복**(사제). 패시브 글은 툴팁의 효과 줄로 간다. / 이름 없이 패시브 글을 그대로 칩에.
5. 역마차·파티 팝업: **막사와 같은 특성 줄**, 파티 팝업의 무대 카드는 아이콘만.
6. 툴팁: **아이콘·이름 / 종류(직업·타고난·얻은)·장점이나 약점·얻은 계기 / 효과**. → 2026-10-19 사용자 "특성은 마우스 우클릭시 툴팁으로 설명 나오게": 카드는 마우스를 올릴 때가 아니라 **우클릭**에 열리고 다음 누름에 닫힌다(아이템 카드와 같음).
7. 정산: **새 특성을 얻은 용병마다 한 줄**(레벨 업 줄 아래).
8. 아이콘: **글자 Placeholder로 구현**하고, 그림은 이미지 API를 요청받으면(특성 열셋 + 직업 다섯 = 열여덟 장. 그림 호출 누계는 상한 $10 가운데 약 $8.41 — Roadmap).
9. 목업에 없는 곳(권장): 전투 화면에는 특성 줄을 두지 않는다. 아이템 카드의 명중·치명타는 주인의 특성을 셈한 값이다(Round 81의 카드 그대로, 꼬리 글은 더하지 않음). 로비 아래 띠의 칩은 그대로.
