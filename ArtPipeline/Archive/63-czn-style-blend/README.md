# Round 63 — 카오스 제로 나이트메어의 그림체를 섞은 발키리 시험 (2026-10-14)

새 그림체를 섞어 보는 시험이다. **지금의 그림체와 게임의 그림은 바꾸지 않는다**(G19: 지금 그림체 유지 그대로).
시험 세트(같은 형식의 스타일 문서와 소재)는 `blend/`에 두고 `gen_image.py`의 `--style`, `--roster`, `--reference`로 돌렸다(Round 06과 같은 길).

## 지시

사용자: "“카오스 오브 제로 나이트 메어” 이미지 스타일을 한번 더해볼까? 이미지 스타일 검색 후 한번 우리 그림체 스타일에 조합해줘 - 테스트 세트로 발키리 이미지 1개 생성".
게임 이름은 슈퍼크리에이티브가 만들고 스마일게이트가 낸 **카오스 제로 나이트메어**(Chaos Zero Nightmare, 2025-10-22 출시)로 읽었다.

## 조사 (2026-10-14)

글 자료(리뷰·개발사 글)와, 브라우저로 본 공식 키 아트·캐릭터 목록·전투 스크린샷에서 읽은 특징이다. 그 게임의 그림은 내려받거나 생성에 붙이지 않았다. 특징만 글로 옮겼다.

| | 읽은 것 |
|---|---|
| 바탕 | 한국 서브컬처(수집형) 게임의 애니메 일러스트. 리뷰는 "애니메 그림 + 음울한 톤", 호러 SF의 아포칼립스 세계로 부른다. 에픽세븐의 2D와 닮았다는 평 |
| 선 | 가늘고 정리된 선, 면의 색에 맞춘 어두운 선. 바깥 외곽선이 우리처럼 굵지 않다 |
| 명암 | 경계가 또렷한 셀 그림자에 부드러운 단계가 조금. 높은 대비, 깊은 그림자, 찬 빛의 림 라이트 |
| 색 | 낮은 채도의 거의 무채색(검정·숯·흰색·찬 회색) 바탕에 **채도 높은 강조색 하나**(키 아트의 자홍·보라, 붉은 머리). 전투는 찬 청색 조명에 자홍·붉은 강조 |
| 얼굴 | 큰 애니메 눈, 또렷한 홍채와 하이라이트, 작은 코, 가는 턱. 가늘고 긴 7~8등신 |
| 옷 | 전술 장비의 겹침: 끈, 버클, 하네스, 벨트, 장갑, 띠 장식. 흰 보디슈트와 메카 날개 같은 SF 디자인도 있다 |
| 전투 화면 | 옆에서 본 작은 전신 캐릭터(2D 애니메이션), 어두운 도시·폐허 배경, 적은 어두운 실루엣에 빛나는 강조색 |

## 섞는 법 (`blend/STYLE_RUNTIME.md`)

지금 게임의 발키리(`output/character/valkyrie.raw.png`)를 기준 그림으로 붙여 캐릭터의 정체와 자세를 지키고, 그리는 방식만 섞었다.

| 지킨 것 (우리) | 가져온 것 (카오스 제로 나이트메어) |
|---|---|
| 금발·땋은 가닥·붉은 털 망토·크림 상의·남색 치마·외날 도끼·주근깨, 오른쪽을 보는 전투 준비 자세, 웃지 않는 얼굴 | 거의 무채색 바탕 + 강조색 하나(망토의 진홍) |
| 굵은 바깥 외곽선(어두운 무대에서의 가독성) | 가는 안쪽 선, 두 단계의 셀 그림자(찬 청보라), 한쪽의 차가운 림 라이트 |
| 탄탄하고 곡선 있는 체형 | 약 5등신으로 조금 길게(지금은 약 4등신), 애니메풍의 눈(홍채·하이라이트 하나·굵은 윗눈꺼풀) |
| 투명 배경, 한 명, 글자 없음 | 가슴 하네스·버클·벨트 주머니·손가락 없는 장갑·끈 감은 부츠 |

SF 갑옷·총·빛나는 장치는 금지에 넣었다(중세 판타지의 재료로만 전술 느낌을 냄).

돌린 명령 (저장소 루트에서):

```text
.venv/bin/python ArtPipeline/tools/gen_image.py --type character --key valkyrie --name valkyrie_czn --style ArtPipeline/Archive/63-czn-style-blend/blend/STYLE_RUNTIME.md --roster ArtPipeline/Archive/63-czn-style-blend/blend/character.csv --reference ArtPipeline/output/character/valkyrie.raw.png
.venv/bin/python ArtPipeline/Archive/63-czn-style-blend/mock_compare.py
```

| Key | 산출물 | 추정 비용 | 후처리 |
|---|---|---|---|
| `valkyrie` | `output/character/valkyrie_czn.png` (보관: `blend/`) | $0.029 | 폭이 넓어 폭에 맞춰 줄임: 키 669 / 목표 806(17% 작음), 반투명 2.3%, 네 모서리 투명 |

- `mock-blend-vs-current.png`: 지금과 시험을 크게 나란히, 머리 2배, 광산 무대 위 게임 크기(기사·고블린 약탈자와 함께).
- `review-blend-vs-current.png`: 파이프라인의 리뷰 시트(게임 표시 크기 300px 줄). 아래의 머리 줄은 시험 그림에서 도끼날을 눈으로 잡아 어긋났다(도구의 한계, 판정에 쓰지 않음).

## 결과 (관찰)

| 특징 | 들어갔나 |
|---|---|
| 색: 재빛 금발, 회백 털, 짙은 진홍, 숯빛 남색 치마, 검은 장화·장갑 | **들어갔다.** 전체가 차갑고 어두워졌다 |
| 전술 장비: 가슴 하네스, 버클, 벨트 주머니, 끈 감은 부츠 | **들어갔다.** 가장 뚜렷한 변화 |
| 비율: 다리가 길어짐 | 조금 |
| 안쪽 선이 가늘어짐 | 조금. 바깥 외곽선도 지금보다 가늘다 |
| 애니메풍의 눈(홍채·하이라이트) | **안 들어갔다.** 얼굴은 지금 그림체의 카툰 얼굴 그대로다 |
| 두 단계 셀 그림자, 차가운 림 라이트 | **거의 안 들어갔다.** 평면 색에 그림자 한 단계, 머리 위쪽에 옅은 밝은 띠 정도 |
| 질감 | 털·장화·도끼날에 결이 생겼다(지금 그림체의 평면 채색과 다름) |

읽은 것:

1. **기준 그림이 이겼다.** 같은 캐릭터를 지키라고 지금 그림을 붙이니 모델이 그리는 방식(얼굴·명암)까지 그 그림을 따랐다. 바뀐 것은 색과 장비, 곧 "옷을 갈아입힌" 정도다. 카오스 제로 나이트메어의 핵심인 애니메 얼굴과 셀 명암은 이 방법으로는 들어오지 않는다.
2. **무대에서는 어두워져 덜 읽힌다.** 광산의 갈색 무대 위에서 시험 그림은 장화·치마·장갑이 배경에 묻고, 지금 그림보다 실루엣이 약하다. 옆의 기사·고블린과는 아직 한 게임으로 보이지만 혼자 색이 차갑다.
3. **키는 지금과 비슷하다.** 자세가 넓어 맞추기가 폭에 걸려 키가 목표(806)보다 작은 675다. 지금 발키리도 같은 까닭으로 630이라 (2026-10-14 Round 64에서 잼) 오히려 7% 크다. 처음 이 줄에 "지금 그림은 목표대로"라고 적은 것은 틀렸다.
4. 한 장으로 바꿀 수 있는 그림이 아니다: 채택하면 용병 여섯·적 다섯·자세(대기·공격·피격·붕괴·각성)와 아이템·UI까지 같은 방향으로 다시 그려야 하고(호출 약 70~90회, 약 $2~3), G19를 다시 연다.

## 판정할 것 (모두 권장안을 적었다)

| # | 질문 | 선택지 | 권장 |
|---|---|---|---|
| 1 | 이 한 장 | a 이 정도(색·장비만 섞임)가 좋다 / b 더 강하게 섞은 것을 보고 싶다 / c 여기서 접는다(G19 그대로) | **b** — 지금 결과는 "섞음"의 시험이 되지 못했다(얼굴·명암이 그대로). 방향을 판단하려면 한 장 더 필요하다 |
| 2 | 더 강하게 섞는 법 (1이 b일 때) | a 같은 기준 그림 + 얼굴·명암·림 라이트를 "바꿔라"로 강하게 적은 문구(호출 1회) / b 기준 그림을 우리 시트(`style_ref_roster.png`)로 바꾸고 캐릭터는 글로만(호출 1회, 정체가 흔들릴 수 있음) / c 둘 다(호출 2회) | **a** — 같은 캐릭터라 지금 것과 공정하게 견줄 수 있다. 그래도 얼굴이 안 바뀌면 b |
| 3 | 채택 시의 범위 (나중) | a 색·장비만(지금 그림체 안의 조정) / b 얼굴·명암까지(그림체 전환, G19 다시 엶) | 시험 뒤에 정한다 |

호출은 지시가 있을 때만 한다. 이 라운드의 상한은 정하지 않았다(그림 누계 약 $6.15 / $10).

## 판정 (2026-10-14)

사용자: **"이 스타일은 안어울리네"** → 이 방향은 닫는다(판정할 것 1~3도 닫음). G19(지금 그림체 유지)는 그대로다. 같은 지시에서 다음 시험(지금 그림체로 더 섹시한 체형 셋, 실사 쪽 + 체인소맨 만화풍 섞음)을 Round 64로 했다(`../64-valkyrie-body-manga/README.md`).
