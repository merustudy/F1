사용자: **"로비(마을) 화면은 배경 이미지로 생성해서 버튼을 눌러 들어가는 방식으로 하자(다키스트 던전 검토 후 차용). 일단 로비 부분 목업 제공해주면 내 확정 후 추후 부분 진행"**.

### 다키스트 던전의 마을(Hamlet) — 가져올 것

- 마을은 그림 한 장이고 건물(역마차, 수도원, 술집, 요양원, 대장간, 길드, 묘지, …)이 그 위의 버튼이다. 마우스를 올리면 밝아지고 이름이 보이며, 누르면 그 건물의 창이 열린다(마을은 뒤에 남는다). 원정에서 돌아올 때마다 마을로 온다.
  역마차는 매주 공짜 후보를 보이고 업그레이드로 후보 수와 로스터 상한이 는다. 술집·수도원은 금으로 스트레스를 푼다. [Hamlet](https://darkestdungeon.wiki.gg/wiki/Hamlet), [Town](https://darkestdungeon.wiki.gg/wiki/Town)
- 우리가 가져오는 것: 그림 한 장 위의 건물 버튼, 마우스를 올리면 밝아지는 건물과 이름표, 누르면 열리는 창(마을은 어두워진 채 뒤에), 원정으로 가는 길(성문의 표지판). 업그레이드(Deeds·Crests)와 묘지·요양원·대장간·길드는 가져오지 않는다(Slice C의 구역은 막사·쉼터·역마차와 원정뿐).
- 건물 넷: **막사**(로스터·레벨·내보내기) — 긴 집과 깃발, **쉼터**(쉬기·치료) — 등불을 단 여관, **역마차**(고용) — 마차와 말뚝, **성문**(원정 화면으로) — 길 끝의 문과 "원정" 표지판.

### 비교

| | 옆 시점 | 내려다본 시점 |
|---|---|---|
| 건물의 읽힘 | 한 줄로 서서 버튼의 자리가 고르다. 다키스트 던전과 같은 무대 느낌 | 지붕·마당·울타리가 보여 "마을"로 읽힌다. 건물의 자리가 들쭉날쭉해 이름표 자리를 건물마다 잡는다 |
| 빈 자리 | 길이 아래 3분의 1. 띠가 길을 덮는다 | 마당이 아래 절반. 띠 위에도 빈 마당이 남는다(나중에 소품·용병의 자리로 쓸 수 있다) |
| 전투 배경과의 어울림 | 같은 옆 시점이라 화면 사이가 매끄럽다 | 원정 화면(지도)과 이어지는 느낌. 전투 무대와는 시점이 다르다 |
| 생성의 변동 | 구도가 단순해 다시 그려도 비슷하게 나온다 | 시점·크기의 변동이 크다(건물을 더하거나 빼면 다시 그릴 때 배치가 바뀔 수 있다) |

권장은 사용자의 취향에 맡긴다. 굳이 고르면 **내려다본 시점**: 마을의 느낌이 살고 빈 마당이 넓어 띠와 창이 들어갈 자리가 넉넉하며, 원정 화면의 지도와 이어진다.

1. 시점: 옆 / 내려다봄.

3. (앞의 판정) 바닥선의 처리, 로비 안 1/2/3, 띠·이름표·창.
