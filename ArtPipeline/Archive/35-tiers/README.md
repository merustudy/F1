# Round 35 — 아이템의 단계 표시, 합치기, 야영지의 정비

목업이다. 호출 없음. Slice B 14단계에서 아이템에 단계(동·은·금·다이아)가 생기고, 같은 아이템·같은 단계를 보드의 칸에 놓으면 합쳐지며,
야영지에서 정비(보드의 아이템 하나를 한 단계 위로)를 할 수 있다(Design/02 §4, 03 §1·§5). 규칙·데이터·저장·시뮬은 이미 들어갔고 Test를 통과했다.
화면은 아직 단계를 보이지 않는다: 아이템 설명의 수치만 단계를 반영한다. 합치기는 지금도 칸을 눌러 되지만 화면이 그것을 알리지 않는다.

## 지시

Slice B의 권장안(2026-10-06, 사용자 "권장대로 구현"): 화면이 바뀌는 곳은 목업으로 먼저 승인받는다. 이 라운드는 14단계의 "단계의 표시"와 야영지의 정비다
(야영지 창은 Round 34 "B"에서 두 카드로 승인됐다. 정비를 누른 뒤의 흐름은 새로 정한다).

## 안

칸의 단계 (`mock-cells.png`, 파티 쪽과 전투. 단계는 스크린샷 위에 꾸몄다):

| 안 | 모양 |
|---|---|
| 지금 | 단계가 보이지 않는다 |
| **A (권장)** | 칸의 안쪽 테(4)가 단계의 색. 동은 지금 그대로(테 없음). 파티 쪽과 전투에 같게 |
| B | 등급 배지(왼쪽 아래)가 단계의 색, 숫자는 그대로. 전투 칸에는 배지가 없어 전투에서는 보이지 않고, 금이 지금의 놋쇠 배지와 같아 보인다 |
| C | 칸 왼쪽 위의 작은 보석(14). 동도 구릿빛 보석 |

- 색: 동 `#B06E3A`, 은 `#8C9CB2`, 금 `#E2A21E`, 다이아 `#2EC4E8`(테. 뼈색 칸과 전투의 어두운 칸 둘 다에서 보이게 짙게). 글자로 적을 때는 밝은 쪽(동 `#D89258`, 은 `#D5DEEA`, 금 `#F7C84A`, 다이아 `#6FE3F8`).

합치기와 보상 (`mock-merge-reward.png`):
- 아이템을 고르면 그것이 **합쳐질 칸**은 어두운 막 위에 "합치기 → 은"과 다음 단계 색의 테를 보인다. 놓으면 그 칸이 한 단계 위가 되고 고른 것은 사라진다(놓을 자리가 차 있어도).
- 고른 아이템의 줄: "단검 · 동 · 등급 8 — …"처럼 단계를 그 색으로 적고, 합칠 수 있는 아이템이면 "같은 단검·동 위에 놓으면 합쳐서 은 하나가 됩니다"를 덧붙인다.
- 보상 카드: 제목에 단계("장궁 · 은 · 등급 8"), 카드 왼쪽에 단계 색의 띠(6). 정예의 보상은 한 단계 위다(예: 금 버클러). 인벤토리 팝업의 줄도 제목에 단계를 적는다.

야영지의 정비 (`mock-camp-upkeep.png`):
- 창에 카드 둘: 쉬기(HP·피로도) | 정비(보드의 아이템 하나를 한 단계 위로).
- 정비를 누르면 창이 정비로 바뀐다: "왼쪽 보드에서 올릴 아이템을 고르세요". 보드의 아이템을 누르면 금색으로 골라지고 창이 그 아이템의 단계와 효과가 어떻게 바뀌는지 보인다
  ("롱소드 동 → 은", "맨 앞 적에게 피해 11 → 22"). [정비하기]로 정하고 다음 층으로 간다. [돌아가기]는 두 카드로 돌아간다.
- 그동안 보드의 아이템 옮기기는 쉰다: 보드를 누르면 정비할 아이템을 고른다. 패널의 "인벤토리로"와 "인벤토리 보기"는 감춘다. 다이아는 고를 수 없다(흐리게).

## 권장: 칸 A, 합치기·보상·정비는 목업대로

- 칸 A: The Bazaar처럼 테의 색이 단계다. 한눈에 읽히고 전투에서도 같은 표시다. 동을 그대로 두면 대부분의 칸은 지금 모습이고 오른 아이템만 눈에 띈다.
  B는 전투에서 안 보이고 금과 놋쇠가 겹친다. C는 작아서 전투의 작은 칸에서 잘 안 읽힌다.
- 정비를 두 걸음(고르기 → 정하기)으로 하는 것은 잘못 눌러 야영지를 써 버리지 않게 하기 위해서다(노드를 고르고 "전투 시작"을 누르는 지금의 흐름과 같다).

4. 정비의 흐름(창에서 두 걸음, 목업대로 / 바꿀 곳). 색도 함께.
