## 지금의 문제

- 아이템 스무 개 중 열하나(기본 무기 다섯 모두)가 **3×1**이다. 틀과 배낭의 폭이 3이라 3×1은 **한 줄을 통째로** 차지한다. 그래서 배낭 3×3은 "줄 셋 = 아이템 셋"이 되고, 돌리기는 3×1을 1×3으로 바꿀 뿐이다.
- 19단계 전에는 용병마다 5칸이었다(크기 1이 열일곱). 지금 시작 배낭에는 기본 무기를 빼면 줄이 둘 남는다. 큰 것은 더 어렵다: 창·장궁 3×2는 기본 무기와 함께면 꽉 차고, **미늘창 3×3은 기본 무기와 함께 들 수 없다**.
- 시뮬(Design/08 §15): 클리어가 18단계보다 3.9%p 낮고(62.2%), 끝날 때 보드의 아이템이 0.8개 적고, 1.24개가 인벤토리에 밀려 있다. 가방은 용병마다 0.2개만 더한다.
- 안 C(큰 것만 줄임)를 재 보니 **시뮬이 그대로**였다(62.2%). 그러니 자리가 모자란 원인은 큰 것이 아니라 전리품의 대부분인 **3×1**(녹슨 칼·조잡한 활·등불 지팡이·치유의 부적)이다.
