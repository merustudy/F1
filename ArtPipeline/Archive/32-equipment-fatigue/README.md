# Round 32 — 장비의 피로: 보드 옆에 "전투마다 피로 +N" — 판정 대기

목업이다. 게임(`Assets`, 화면 코드, 데이터)은 그대로다. 호출 없음.

## 지시 (2026-10-06, 사용자)

11단계(새 Slice B의 범위) 보고에서 무기 스테미나 대신 사용자가 제안했다: "무기 쌓기를 방지하기 위해 무기 장비는 전투에 들어갈 때 피로도(+1)를 추가로 더하는 방식은 어때?"
세부 다섯(권장안 함께 보고)에 사용자가 답했다:

1. 무엇을 셀까: "기본무기만 피로도 제외 나머지 얻게되는 장비류는 +1씩" (권장안 "둘째 무기부터"를 바꿈)
2. 개수냐 칸이냐: "개수"
3. 어디의 장비: "권장안" — 보드에 있는 것만, 그 자리에서 쓸 수 있는지는 따지지 않는다. 인벤토리는 0
4. 값: "권장안" — 데이터 상수 하나, 출발값 1, 시뮬로
5. 화면: "목업 제공" — "목업 제공해줘. 승인 후 구현 시작"

## 이 목업에서 정한 것 (권장안, 판정 대기)

- **"장비류" = 무기 장비 + 방어 장비**로 읽었다(분류 다섯 가운데 이름에 "장비"가 붙은 둘: Design/02 §4). 그래서 버클러도 +1이고, 공격 아이템(불씨 플라스크)·지원 아이템(약초 주머니, 수호 부적)은 0이다.
  무기 장비만이라면 버클러의 표시만 빠진다.
- 피로의 색은 새 색 **연보라**(`#CFBAF7`, 표의 바탕 `#2C1A3A`, 테 `#9E84DA`). 화상의 주황, 쿨다운의 금빛, 보호막의 파랑과 겹치지 않게 했다.
- 합계가 0인 용병(엘라)은 보드 머리에 아무것도 쓰지 않는다.
- A·B·C 공통: 장비인 **보상 카드**의 설명 줄 끝에 "/ 전투마다 피로 +1", 노드 맵에서 **고른 아이템의 줄** 끝에 얻은 장비는 "/ 전투마다 피로 +1", 기본 무기는 "/ 기본 무기: 피로 없음".
- 전투 화면에는 이번에 아무것도 더하지 않는다. 피로를 원정 안에서 쌓는 방식(11단계 보고의 4번)이 정해지면 전투 중의 피로 표시와 함께 목업으로 정한다.

## 안

| 안 | 피로를 내는 칸 | 보드 머리(이름 띠) |
|---|---|---|
| 지금 | 표시 없음 | 표시 없음 |
| A | 표시 없음 | 오른쪽 끝에 합계 "피로 +N" |
| **B (권장)** | 칸의 오른쪽 위에 "+1" 표 | 오른쪽 끝에 합계 "피로 +N" |
| C | 칸의 오른쪽 위에 "+1" 표 | 표시 없음 |

- 보드는 모든 안에서 같은 예(원정 중반쯤)로 채웠다: 미라 = 화염 지팡이(기본) + 장궁(+1), 엘라 = 치유의 지팡이(기본) + 약초 주머니·수호 부적(0),
  카이 = 소드(기본) + 창(+1) + 불씨 플라스크(0), 로언 = 롱소드(기본) + 버클러(+1) + 단검(+1). 스크린샷에는 기본 무기만 있어서 칸은 게임의 조각(`slot`)과 아이콘으로 이 스크립트가 그렸다("지금"도 같은 코드).

## 권장: B

- 어느 아이템이 피로를 내는지(칸의 표)와 그래서 얼마인지(머리의 합계)가 보드 하나에서 다 읽힌다. 보상을 넣거나 아이템을 옮기는 그 자리에서 비용이 바뀌는 것이 보인다.
- 규칙("기본 무기는 0, 얻은 장비는 하나에 +1")을 따로 설명하지 않아도 보드를 보면 배운다. 기본 무기에 표가 없는 것이 곧 예외다.
- A는 합계만 있어 무엇을 빼면 줄어드는지 보이지 않는다. C는 더해야 하고, 머리의 "피로"라는 말이 없으면 칸의 "+1"이 무엇의 +1인지(등급? 피해?) 헷갈린다.
- 대가: 칸 오른쪽 위의 표가 아이콘의 끝(칼끝, 활 끝)에 조금 겹친다. 등급 배지가 왼쪽 아래에서 손잡이에 겹치는 것과 같은 정도다.

## 판정할 것

1. 지금 / A / B / C 가운데 하나.
2. "장비류"의 뜻: 무기 장비 + 방어 장비(이 목업) 또는 무기 장비만.
3. 피로의 색(연보라), 0이면 표시 없음, 보상 카드와 고른 아이템 줄의 문구.

## 구현의 전제

이 규칙은 **피로가 원정 안에서 쌓일 때만** 뜻이 있다(11단계 보고의 4번: B "다키스트 던전 스트레스처럼" 또는 C "가벼운 DD"). 지금의 피로(원정이 끝날 때 30을 뺀다)에서는 전투에 들어갈 때 더할 곳이 없다.
그래서 4번(과 범위 문서)이 정해져야 구현한다.

## 두 번째 목업: 보드 머리의 합계에 틀

칸의 "+1" 표, 보상 카드와 고른 아이템 줄의 문구는 B안 그대로다. 바뀌는 것은 보드 머리(이름 띠)의 합계뿐이다.
합계는 띠의 오른쪽 끝에서 5 안(칸의 표가 칸의 끝에서 떨어진 만큼), 이름 글자와 같은 높이에 놓는다.

| 안 | 머리의 합계 |
|---|---|
| B (지난 목업) | 연보라 글만 "피로 +N" |
| **B1 (권장)** | 칸의 표와 같은 표(자주 바탕, 연보라 테, 같은 높이 20·글 13)에 "피로 +N". 너비는 글에 맞춘다 |
| B2 | 칸과 같은 뼈색 틀(아이템 칸의 `slot`을 줄인 것)에 짙은 보라 글 "피로 +N" |
| B3 | 칸의 표와 똑같은 표에 숫자만 "+N" |

- 권장 B1: 연보라 표 = 피로라는 한 가지 모양이 칸과 머리에 같이 쓰여 둘이 한 묶음으로 읽힌다. "피로"라는 말이 남아 처음 보는 사람도 뜻을 안다.
- B2는 머리가 또 하나의 아이템 칸처럼 보여 누를 수 있는 칸과 헷갈릴 수 있고, 연보라 = 피로의 묶음이 약해진다. B3는 가장 깔끔하지만 "피로"라는 말이 없다.
