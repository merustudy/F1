# Round 75 — 원정 파티를 팝업에서 꾸리기 (2026-10-17 사용자 "원정 로스터는 원정 버튼 누르면 팝업으로 로스터 구성 제공(유사게임 검토 후 권장안 구현)")

사용자가 "검토 후 권장안 구현"으로 정했으므로 판정을 기다리지 않고 권장안 B를 구현했다. 목업 셋은 사후 검토의 자료다(사용자 규칙: 배치는 목업으로 — 지금 것과 안 셋을 나란히 `mock-party-compare.png`).

## 지금

- 로비(26단계, Round 71): 파티와 열은 **막사 창**의 열 버튼과 [제외]로 꾸린다. 띠의 [원정 화면으로]와 성문은 파티가 비었으면 꺼진다.
- 원정 화면(Round 71 E2): 지도·던전 정보·**파티는 보기만**·[출발]. 사용자는 Round 71에서 E1(원정 화면 아래 띠에서 꾸림)보다 E2를 골랐다.
- 그래서 새 플레이어는 막사를 먼저 찾아야 원정을 갈 수 있고, 원정 화면에서 파티를 바꾸려면 로비로 돌아가야 한다.

## 유사 게임의 파티 편성

| 게임 | 어디서 | 어떻게 |
|---|---|---|
| 다키스트 던전 | 마을의 **출정(Embark) 화면**: 퀘스트를 고른 뒤 같은 화면에서 | 오른쪽 로스터에서 영웅을 네 자리에 넣고(클릭·끌기), 자리를 끌어 바꾼다. 보급품을 산 뒤 Embark. 마을의 로스터 목록은 관리(치료·훈련)만 하고 파티는 출정 화면에서만 짠다 |
| 다키스트 던전 2 | 여정의 시작·여관 | 네 명을 고르고 여관에서 자리를 맞바꾼다 |
| 이라투스: 로드 오브 더 데드 | **전투 앞의 편성 창** | 네 칸에 수하를 넣고 자리마다 기술이 달라 자리를 고른다 |
| 배틀 브라더스 | 세계 지도의 **편성 화면**(전투 앞) | 로스터(예비·전열)에서 자리에 끌어 넣는다 |

공통: **로스터 관리(고용·치료·해고)와 파티 편성을 떼어** 두고, 편성은 **떠나기 직전**에 한다. 자리 바꾸기는 끌기가 보통이지만 버튼으로도 충분하다(우리 막사의 열 버튼, 이라투스의 화살표).

## 안 셋 (`mock-party-compare.png`)

| 안 | 팝업을 여는 것 | 팝업 안 | 장단 |
|---|---|---|---|
| A | **로비의 [원정 화면으로]·성문** | 열 칸 넷 + 로스터 칩 + [원정 화면으로] | 글자 그대로 "원정 버튼이 팝업". 그러나 던전을 보기 전에 파티를 짜고, 원정 화면의 파티는 보기만이라 바꾸려면 로비로 되돌아간다 |
| **B (권장)** | **원정 화면의 [출발]** | 고른 던전의 줄 + 열 칸 넷 + 로스터 칩 + **[출발]** | 던전(심연인지, 며칠인지)을 알고 짠다. 팝업이 출발의 확인 창을 겸한다(피로를 한 번 더 본다). 로비의 원정 단추는 파티가 비어도 열린다 |
| C | 원정 화면이 **열리면 저절로**, 띠의 [파티 편성]으로 다시 | B와 같고 [확인]으로 닫음, 출발은 화면에서 | 처음 한 번은 편하지만 들어올 때마다 뜬다(원정 뒤 같은 파티로 또 갈 때 거슬림) |

권장은 **B**다. 다키스트 던전처럼 "던전을 고른 뒤 그 자리에서 파티를 짜고 떠난다"가 되고, 팝업이 하나뿐이며 새 단추가 없다.

세부(권장안으로 정함, 사후 검토):
- 넣기는 **칩 누름**(비어 있는 맨 앞 열로). 파티 안의 칩을 누르면 뺀다. 가득 찼으면 아무 일도 없다(안내 줄이 상태를 말한다).
- 자리 바꾸기는 열 칸의 **[앞으로][뒤로]**(그 열에 선 용병과 맞바꿈, 아무도 없으면 꺼짐). 끌어 놓기는 두지 않는다(손의 규칙이 보드의 것과 겹친다).
- 막사의 열 버튼·[제외]는 **그대로** 둔다(같은 `RunManager` 명령). 직접 플레이 뒤 막사에서 열 버튼을 빼는 것이 권장이다(로스터 관리와 편성을 떼는 유사 게임의 방식).
- 로비의 [원정 화면으로]·성문은 **파티가 비어도** 열린다(런이 끝났을 때만 꺼짐). 원정 화면의 [출발]도 파티가 모자라도 팝업을 연다(잠긴 던전·끝난 런이면 꺼짐). 팝업의 [출발]만 파티가 갖춰져야 켜진다.
