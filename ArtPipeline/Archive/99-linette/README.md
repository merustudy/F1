# Round 99 — 리넷의 일러스트

2026-10-23 사용자 "리넷은 우선 일러스트 확정 후 다시 그려보자", 이어서 안 셋(A 차가운 서기, B 학자 소녀, C 잿빛 단발)을 보이자 **"C느낌으로 하나 만들어줘"**.
리넷은 `Docs/Design/33_Black_Lily_Story_Summary.md` §4의 인물이다(하이데 역, 왕의 공물 장부를 쓰던 노예, 검은 백합의 첫 단원).
이 그림이 확정되면 인트로 #8(Round 98 02판)을 이 그림을 붙여 다시 그린다.

## 만든 것

| 파일 | 무엇 |
|---|---|
| `linette.csv` | 소재. `character` 타입의 형식(용병 전신 그림, 오른쪽을 봄, 투명 배경)이고 얼굴 기준은 `subculture_60`이다 |
| `review_sheet.py` | 호출 없음. 인트로 01판 #8의 리넷, 새 그림(게임 크기의 캔버스), 얼굴 확대, 마리안(과거)을 한 장에 세운다 |
| `review_c.jpg` | C안의 리뷰 시트 |

**올린 사진은 Git에 넣지 않는다.** `refs/`의 사용자가 올린 사진 다섯 장(`linette_d_face_ai.jpg`, `linette_front_face_ai.jpg`, `portrait_face_ai.jpg`, `portrait_outfit_ai.jpg`, `portrait_ref_illust.jpg`)은 로컬에만 둔다(2026-10-23 세션 정리). 이 기록의 명령이 그 파일을 가리키면 로컬에서만 다시 돌릴 수 있다.

**Key는 자리표다.** `character` 타입은 Roster의 Key를 `JobData.Id`로 검사한다. 리넷은 직업이 아니므로 Key를 `rogue`로 두어 검사를 지나게 하고, 산출물의 이름을 `--name linette_c`로 달리했다. 생성 도구와 스타일 문서는 바꾸지 않았다. 리넷 같은 NPC 그림이 늘면 정식 타입(`npc`)을 더하는 일을 13 Owner 문서와 함께 정한다.

```text
.venv/bin/python ArtPipeline/tools/gen_image.py --type character --key rogue --name linette_c \
  --roster ArtPipeline/Archive/99-linette/linette.csv
```

## 호출

1번, 약 $0.032(`gpt-image-2.5-sunburst`, medium, 1024x1024, 투명). 누계는 약 $11.15다(상한 $20).

## D안: 올린 AI 인물 사진을 바탕으로

같은 날 사용자가 사진 두 장을 올리고 "업로드 이미지 기반으로 우리 그림체 리넷 이미지 생성"이라고 했다. 그중 한 장은 실제 공연 사진으로 보였다. 실제 인물의 얼굴을 옮기지 않으려고 스타일만 글로 옮기는 호출을 냈고, 사용자가 이를 멈췄다.
이어서 사용자가 **"업로드 이미지(Ai 인물) 기반으로 우리 그림체 리넷 이미지 생성"**이라며 AI로 만든 인물 사진 한 장만 다시 올렸다.

- 그 사진(`refs/linette_d_face_ai.jpg`)을 우리 기준 그림(용병 시트) 뒤에 두 번째 기준 그림으로 붙였다(`--extra-reference`).
- `--extra`로 사진에서 가져올 것만 적었다: 머리 모양, 얼굴형, 눈과 아이라인, 왼쪽 눈 밑의 점, 붉은 입술. 사진의 사실적인 그림결, 빛, 피부 질감은 가져오지 않는다.
- 소재 `linette_d.csv`: 윤기 있는 검은 단발, 두꺼운 일자 앞머리, 바깥으로 뻗친 끝, 왼쪽 눈 밑의 점, 붉은 입술, 쇠고리 자국을 가리는 검은 리본 초커, 어깨가 드러난 검은 드레스, 잉크병과 깃펜 통을 찬 가죽 띠, 장부, 잉크 묻은 손끝.

```text
.venv/bin/python ArtPipeline/tools/gen_image.py --type character --key rogue --name linette_d \
  --roster ArtPipeline/Archive/99-linette/linette_d.csv \
  --extra-reference ArtPipeline/Archive/99-linette/refs/linette_d_face_ai.jpg --extra "<위의 문장>"
```

호출 1번, 약 $0.045(기준 그림이 둘이라 입력이 늘었다). 누계는 약 $11.19다.

|---|---|
| 검은 단발, 두꺼운 일자 앞머리, 바깥으로 뻗친 끝 | 맞다(사진의 머리 모양) |
| 아이라인, 붉은 입술, 눈 밑의 점 | 맞다 |
| 검은 리본 초커, 어깨가 드러난 검은 드레스(옆트임), 가죽 띠의 잉크병과 깃펜 통 | 맞다 |

| 마리안(갈색 곱슬)과 구별되나 | 된다 |

## 대화 7·8-2·8의 손: 잉크 얼룩과 검은 손톱 지우기 (호출 없음)
