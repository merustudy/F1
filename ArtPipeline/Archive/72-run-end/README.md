## 지금 로비(도형)에 들어간 것 (25단계 구현)

- 결과 판의 제목이 승리·패배의 까닭을 말한다(`Lobby.Victory`·`DefeatDeathLimit`·`DefeatFinalStand`·`RunOver`), [새 런]은 그대로.
- 기한을 넘기면 출발 안내 줄이 금빛 "기한이 지났습니다. 최종 결전으로 출발합니다"이고 던전 칸이 심연을 보이며 쉬기 단추가 꺼진다.
- 정산 화면의 마지막 줄이 "최종 보스를 쓰러뜨렸습니다. 런이 끝났습니다" 등으로 까닭을 말한다.

## 판정할 것

1. 결과 창의 모양(제목·네 줄·[새 런])과 창에 적는 것(원정을 던전별로 셀지, 살아남은 용병을 적을지).
2. 최종 결전 상태의 표시: 헤더의 금빛 글, 성문의 이름표 바꿈, 쉼터 닫힘.
3. 이 목업은 26단계(마을 로비)에서 구현한다. 지금 로비의 글만 바뀐 것으로 25단계를 닫아도 되는지.

## 판정 (2026-10-16) — 권장안대로

사용자 **"권장안대로 구현"**: 셋 다 목업대로. 26단계가 마을 로비와 함께 구현했다(Architecture/12 "로비: 마을").

1. 결과 창: 어둡게 한 마을 위의 창(900x500, 놋쇠 선), 제목(승리 금빛·패배 붉음, 까닭), 줄 넷 — 끝난 날, 원정 N회 (던전별), 전사자 N명, 살아남은 용병 —, [새 런]. 던전별 횟수는 `RunState.ExpeditionsByDungeon`(저장 14. 옛 저장은 "N회"만).
2. 최종 결전 상태: 헤더가 금빛 "101일차 / 100일 — 최종 결전", 성문의 이름표가 "최종 결전"과 "심연의 보스와 싸운다", 쉼터의 이름표가 흐리고 "쉴 날이 없다", 띠의 단추가 [최종 결전으로]. 쉼터의 창은 쉬기가 꺼지고 치료는 된다.
3. 25단계는 글만 바뀐 로비로 닫혔고(이미 완료), 이 목업은 26단계에서 구현했다.
