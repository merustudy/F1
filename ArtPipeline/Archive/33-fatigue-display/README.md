# Round 33 — 로비의 피로도 표시 — 판정 대기

목업이다. 호출 없음. Slice B 12단계에서 피로도가 0에서 쌓이는 값(0~200)이 되었다(Design/04 §3: 100에서 붕괴 판정, 200에서 쓰러짐 — 판정과 쓰러짐은 15단계).
로비의 로스터 줄은 지금 뜻만 바뀌었다: "피로도 N/200"과 쌓인 만큼 차는 **녹색** 막대(전의 "남은 피로"의 모양 그대로). 피로는 나쁜 쪽으로 차므로 모양을 다시 정한다.

## 지시

Slice B의 권장안(2026-10-06, 사용자 "권장대로 구현"): 화면이 바뀌는 곳은 목업으로 먼저 승인받는다. 이 라운드는 그 가운데 12단계의 로비 표시다.
파티 쪽(노드 맵·보상)과 전투에서 지금 피로를 보이는 자리는 15단계에서 정한다(그때 붕괴·각성의 표시와 함께).

## 안

| 안 | 막대 | 글 |
|---|---|---|
| 지금 | 녹색, 쌓인 만큼 | "피로도 N/200" 흰 글 |
| A | 피로의 연보라(장비 피로 표의 테 색), 100 자리에 뼈색 눈금 | 흰 글 그대로 |
| **B (권장)** | A + 100을 넘은 부분이 붉은 보라(위험) | 100 아래는 연보라, 넘으면 붉은 보라 |
| C | 칸 열 개(20씩, 사이 4). 앞의 다섯은 연보라, 뒤의 다섯(100 넘음)은 붉은 보라 | B와 같다 |

- 예로 넣은 값: 아스트리드 0, 세드릭 12, 엘라 54, 카이 86, 미라 61, 로언 128(원정 하나와 쉬는 날 뒤쯤).
- 색: 연보라 `#9E84DA`(막대), `#CFBAF7`(글, `UiPalette.Fatigue`), 붉은 보라 `#C84B6E`, 눈금 뼈색 `#E8DEC8`.

## 권장: B

- 피로는 장비 피로 표와 같은 연보라로 묶인다(피로 = 연보라). 100의 눈금과 그 너머의 붉은색이 "어디서부터 위험한가"를 막대 하나로 말한다.
- 글까지 붉어지면 로스터를 훑어볼 때 100을 넘은 용병이 바로 보인다(쉬게 할지, 보낼지).
- A는 차분하지만 100을 넘었는지 눈금으로만 읽힌다. C는 다키스트 던전의 칸처럼 셀 수 있지만 막대가 잘게 쪼개져 다른 막대(HP)와 모양이 다르고, 100 너머의 의미는 B와 같다.
