## 둘째 지시 — 유사 게임 검토와 생성한 그림으로 목업 (2026-10-17, 호출 7회 약 $0.16)

첫 목업의 자리 표시(약초 주머니 아이콘)는 가방으로 읽히지 않았다. 유사 게임을 보고 가방의 그림 방향 셋을 정해 **이미지 API로 실제 그림**을 만들어 화면에 얹었다.

### 유사 게임

- **백팩 배틀즈**([Bag](https://backpackbattles.wiki.gg/wiki/Bag), 위키의 그림을 브라우저로 봄): 가방은 격자에 놓는 아이템이고 칸을 더하며 대개 효과가 있다(Leather Bag 4칸, Fanny Pack 2칸, Potion Belt 4칸 한 줄, Holdall 6칸 …). 그림은 **가방을 위에서 본 납작한 가죽 모양**으로, 그 윤곽이 칸의 발자국과 같다(Leather Bag은 바느질 테의 갈색 정사각, Fanny Pack은 덮개 달린 주머니, Offering Bowl은 위에서 본 그릇). 아이템은 그 위에 놓인다. 상점에서도 같은 그림이다.
- **백팩 히어로**([wiki](https://backpackhero.wiki.gg/)): 3×3 배낭에서 시작해 격자가 자라고, 가방은 픽셀 아트의 가방 윤곽 안의 칸이다(리뷰 글, 그림은 못 봄).
- 우리가 가져올 것: 가방이 "물건"일 때도 **가방의 윤곽이 칸 수를 말하게** 하는 것(백팩 배틀즈의 발자국). 보드 위의 우물(칸)은 그대로 둔다.

## 셋째 지시 — 안 2로, 칸을 보드의 네모 칸에 맞춰 다시 그림 + 보드의 두 방식 (2026-10-17, 호출 3회 약 $0.07)

사용자: **"안2번식으로 가는데 칸은 인벤 네모칸에 최대한 맞추어 이미지 생성해줬으면 / 한번 가방 설치하면 칸이 기존 칸으로 늘어나는 방안과 가방이미지를 뒷 배경으로 두는 방안의 각 목업 제공해줘"**.

- 소재 `look2b.csv`: 정확히 위에서 본 평면도, 입 안이 똑같은 정사각 칸 N개(3·2·9)로 곧은 바느질 가죽 띠로 나뉘고, 테는 고른 폭으로 캔버스 끝까지, 안은 비어 있고 덮개·끈·무기 없음. `generate2.sh`(`generate2.log`) → `output/bag/<가방>_look2b.png`. 이번엔 배낭에 무기가 들어가지 않았다.
- 칸 맞춤: `item` 타입의 캔버스는 보드 조각의 2배(3×1 → 328x100 ↔ 화면 164x50)라 입이 캔버스를 거의 채우면 칸이 보드의 칸 자리에 온다. 목업은 원본에서 입(어두운 칸 영역)을 재어 격자에 맞춰 깔았다(`mock_board.py`의 `opening`·`picture_under`). 구현에서는 같은 측정을 파이프라인의 후처리로 두어(`fit=bagwell`: 입을 칸 N×M에 맞춘 캔버스로) 화면이 계산하지 않게 한다.
- 보드의 두 방식(`mock-bag-board.png`):
  - **(a) 칸만 늘어남**: 가방을 놓으면 지금의 우물(돌 테 + 검은 칸)이 그대로. 그림은 물건일 때(바닥·상점·손)만. 보드의 읽힘(디아블로의 검은 칸)이 그대로고 구현이 작다(그림을 세 자리에만 더함).
  - **(b) 가방 그림이 칸의 뒷배경**: 놓인 자리에 그림을 격자에 맞춰 깔고 **그림의 칸이 곧 보드의 칸**(검은 칸을 따로 그리지 않음), 가죽 테와 바느질이 칸 사이·둘레로 보인다. 아이템은 그 위에. 가방이 보드에서도 가방으로 읽히고 물건일 때와 같은 그림이라 집어 들고 놓을 때 이어진다. 대신 칸의 바탕이 검정 → 어두운 갈색이라 아이템 조각(남색)과 빈 칸의 대비가 조금 줄고, 든 동안·놓이는 그림자·고른 가방의 금 테 같은 상태 표시를 그림 위에 다시 맞춰야 한다(구현 중간).
- 권장: **(b)**, 단 시작 가방(배낭 3×3)도 같은 그림으로(보드의 가방 셋이 한 문법). 칸 바탕의 대비는 그림의 칸을 지금의 검정에 가깝게 어둡게 보정해(파이프라인의 후처리, 호출 없음) 지킨다.

### 판정할 것

1. 보드: **(b) 그림이 뒷배경** / (a) 칸만.
2. (b)면 칸 바탕: **그림의 칸을 검정에 가깝게 어둡게 보정** / 그림 그대로(갈색).
3. 그림 셋: **이대로 확정** / 고칠 점(테의 두께, 버클·고리, 색) / 다시 그리기.
4. 상점 타일의 바탕과 바닥 이름판의 칸 수: 둘째 지시의 판정(권장: 가죽 색 판, "3×1" 붙임).

- 장단: 가방이 "설치"가 되어(사용자의 말, 건물처럼) 조작이 단순해지고 **놓는 자리가 결정**이 된다(어디에 두면 어떤 아이템이 ★에 닿나). 대신 잘못 놓으면 그 원정 내내 그대로고(아이템은 여전히 자유로이 옮긴다), 죽은 용병의 가방을 살리는 길은 없어진다(지금도 죽으면 보드가 사라지니 같다). 놓기 전의 초록 그림자(미리보기)가 유일한 확인이다.
- 선택지: **(1) 완전 고정**(사용자의 방향. 권장: 규칙이 하나 줄고 Backpack Battles와 달리 우리는 전투 사이의 정리가 짧아 옮길 일이 드물다) / (2) **빈 가방만** 옮김(안에 아이템이 있으면 고정 — 실수의 되돌림은 남기고 "아이템이 든 가방 = 설치") / (3) 지금처럼.
