# Round 05 — 전투 UI (`ui_frame`, `ui_icon`)

UI의 틀과 상태 아이콘이다. 소재는 `Rosters/ui_frame.csv`, `Rosters/ui_icon.csv`의 `Subject`, 그리는 방식은 `STYLE_RUNTIME.md` §14~§18이다.
호출은 `gpt-image-2.5-sunburst`, `medium`, 투명 배경. 틀은 `Size`의 비율에 가까운 캔버스로 생성한다. 장부는 `../calls.csv`.

## 사용자 지시 (2026-10-02)

- "전투 관련 Ui 관련 이미지 생성 - 유사 유명 게임 검토 후 최선안 적용"
- "현재 그림체 스타일도 반영해서 생성"

## 검토한 게임과 가져온 것

스토어의 스크린샷을 실제로 열어 봤다(Steam: Darkest Dungeon, Slay the Spire, The Bazaar, Backpack Battles). 규칙은 위키와 검색 결과로 확인했다.

| 게임 | 전투 UI에서 본 것 | 가져온 것 |
|---|---|---|
| Darkest Dungeon | 무대 위의 유닛 발밑에 가는 HP 막대, 고른 대상에 꺾쇠, 어두운 틀에 강조색 하나, 상세는 아래 패널 | HP를 발밑에 둔다. 무대를 가리는 큰 판을 없앤다 |
| Slay the Spire | HP 막대 위에 숫자("45/82"), 상태는 막대 아래에 아이콘과 숫자, 포션은 위쪽 띠의 칸 | 숫자를 막대 위에, 상태는 아이콘+숫자, 포션 띠 |
| The Bazaar | 아이템이 크기(1~3칸)만큼의 타일이고 타일 자체에 쿨다운과 수치가 붙는다. 큰 HP 막대에 숫자 | 아이템 칸 자체가 쿨다운 표시다(따로 막대를 두지 않는다). 크기는 칸의 수로 보인다 |
| Backpack Battles | UI가 그림과 같은 손으로 그려져 있다(양피지, 리본, 나무 팻말). 아이콘만으로는 헷갈린다는 이용자 의견이 있다 | UI의 틀을 유닛과 같은 그림체로 그린다. 아이콘에는 늘 숫자나 글자를 붙인다 |

우리 전투는 여덟 유닛의 아이템이 동시에 돈다. 그래서 Darkest Dungeon처럼 고른 유닛 하나의 상세 패널을 두지 않고, 유닛마다 제 칸을 전부 보여 준다.

## 최선안 — 확정 (2026-10-02)

목업은 `mock-battle.png`(4 대 4, 빈사·보호막·화상 포함), `mock-compare.png`(지금의 게임 화면과 같은 순간의 새 UI), 조각은 `review-kit.png`.

- **명패** (180x92, 캐릭터 발밑): 열 번호 배지, 이름, HP 막대(숫자가 막대 위에), 상태 줄(보호막과 화상은 아이콘+숫자, 빈사는 해골+남은 유예와 피격 수).
  편의 색은 명패의 색이다(아군 남색, 적 붉은 갈색). 빈사는 붉은 명패, 포션 대상은 밝은 파랑.
- **아이템 칸** (180x60, 3:1. 간격 4): 명패 아래에 세로로 쌓인다. 칸 자체가 쿨다운 표시다(왼쪽부터 차오른다). 크기 2는 180x124, 크기 3은 180x188.
  빈 칸은 흐리다. 지금은 이름 글자를 적고, 아이콘은 이 크기가 확정된 뒤에 가로로 그린다.
- **큰 색 카드를 없앤다.** 명패와 칸만 남아 화면 아래쪽에 배경이 보인다.
- **열 번호**는 머리 위의 글자가 아니라 명패의 배지다.
- **헤더**(높이 84)와 **포션 띠**는 지금의 자리 그대로, 패널과 버튼과 칸의 그림을 입힌다. 폭풍은 아이콘과 함께, 포션 안내문은 작은 판 위에.
- **재질**: 남색 패널에 놋쇠 선과 모서리의 징, 남색 명패에 크림색 선, 어두운 칸, 청회색 버튼. 굵은 외곽선, 평면 채색, 낮은 채도.

- 결과: 여덟 다 정면에서 본 납작한 그림으로 나왔다. 틀 넷은 안이 비어 있고 네 변이 곧다. 그림자와 글자가 없다. `storm`의 구름에는 작은 흰 반사가 있다.
- 후처리(`frame`, `glyph`): Alpha로 오려 내 `Size`(화면 크기의 2배)로 맞추고, 유닛의 외곽선 색(24, 9, 7)으로 고른 띠(6px. 화면에서 3px)를 둘렀다.
  `plate`, `slot`, `button`의 `Size`는 그림을 본 뒤에 그린 비율과 쓰는 크기에 맞춰 고쳤다(`--refit`. 호출 없음).
- 틀의 바탕색을 한 색으로 고르게 편다(모델이 남긴 옅은 얼룩을 없앤다. `frame` 후처리). 색만 다른 변형은 한 장에서 바탕색을 바꿔 만든다
  (`tools/ui_variants.py`, `Rosters/ui_variant.csv`): 명패 다섯(`plate_party`, `plate_enemy`, `plate_danger`, `plate_target`, `plate_label`),
  칸 둘(`slot`, `slot_selected`), `panel`, 그리고 화면이 색을 입혀 쓰는 흰 바탕의 `button`. 게임에 들어가는 틀은 이 아홉 장이다.
  HP 막대의 틀은 `slot`을 줄여 쓴다. 열 번호 배지와 막대의 채움, 쿨다운의 채움은 코드로 그린다.
