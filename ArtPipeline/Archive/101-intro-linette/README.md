## 데이터만 고치면 되는 것

| 바꾸고 싶은 것 | 고치는 곳 |
|---|---|
| 장면을 더하거나 빼거나 차례를 바꿈 | `StorySceneData.csv`의 행과 `Order`(10씩 띄워 사이에 넣음), 새 그림 PNG |
| 자막, 목소리(흰색·금색), 짧은 판에 남는 줄 | 그 행의 `Line*`·`Line*Voice`·`ShortLines` |
| 장면의 시간, 움직임, 넘김 | `DurationMs`·`ShortDurationMs`·`Motion`·`Transition` |
| 본 그림으로 바꿈 | 같은 주소의 PNG만 바꿈(또는 `Image`) |
| 대사, 화자, 표정, 대화가 나오는 때 | `DialogueLineData.csv`, `DialogueData.csv`의 `Trigger`·`Dungeon` |
| 표정을 더함 | `NpcData.csv`의 `Portraits`에 `이름:주소`, 그림 PNG |

코드가 아는 것은 틀뿐이다: 목소리 셋의 색, 움직임 일곱과 넘김 둘의 모양, 계기 둘(런의 첫 로비, 던전이 열린 뒤), 줄이 뜨는 간격.

## 판정할 것 (권장안은 굵게)

1. 이야기 데이터의 길: **CSV → Generated JSON(`LocalizedText`) 넷**(자막이 그 장면의 그림·시간과 같은 행. 장면을 더해도 코드가 바뀌지 않음) / UI String Table(장면을 더할 때마다 `UiKeys` 상수가 늘어남).
2. 언제 보이나: **새 런마다. 처음은 본편, 그 뒤는 짧은 판** / 새 런마다 본편 / 처음 한 번만(그 뒤에는 [인트로 보기]로만).
3. 넘기기: **클릭·스페이스 = 다음 장면, Esc·[건너뛰기] = 끝까지** / 아무 키나 끝까지(33 §9의 출발값, Round 98 움직임 목업의 방식. 잘못 눌러 128초를 다 놓치기 쉬움) / 길게 누르기.
4. 다시 보기: **타이틀 설정 줄의 [인트로 보기], 늘 본편** / 두지 않음.
5. 봤다는 표시: **`settings.json`의 `IntroSeen`(설정 버전 3)**(사람마다의 사실. 새 런이 덮지 않음) / `run.json`(새 런마다 지워짐) / 두지 않음(늘 본편).
6. 움직임: **장면마다 `Motion` 하나(배율 1.00↔1.10의 밀기·확대, 옆·위아래 흐름), 겹쳐 넘김 0.8초, 검게 닫기 0.6초(#4·#6 뒤), 줄은 0.6초부터 2.2초 간격** / 다른 세션의 Round 98 움직임 목업(`98-intro-storyboard/make_motion.py`)의 연출을 더함 — #4의 흔들림, #10의 심장 박동 어둠, 글자 수에 비례한 줄 시각. 더하면 데이터에 효과 열(`Effect`: `Shake`·`Heartbeat`)이 생긴다. 권장은 지금은 빼고 본 그림 라운드 뒤에 보는 것.
7. 소리: **지금은 새 소리 없음, 타이틀의 로비 곡이 그대로 이어짐**(장면의 소리 메모는 `SoundNote`에) / 인트로 동안 음악을 끔(새 `StopMusic`이 필요).
8. #13: **실제 로비 화면 위의 띠**("일식까지 99주"와 "첫 마을 — 광산 마을", 4초 또는 누르면 사라짐) / 인트로 안에서 터 그림 위에(건물이 없는 빈 터가 보임).
9. #3의 첫 줄: **혼잣말과 따옴표를 두 줄로 나눔**("왕이 우리를 불렀다." / "“구덩이를 쳐라. …”" — 색이 줄마다라서. 세 줄 규칙 안) / 한 줄 그대로(한 색).
10. 리넷의 대화가 나오는 곳: **안 A(첫 로비와 새 마을이 열린 뒤의 대화) + 안 B(마을의 리넷: 누르면 마지막 대화를 다시)** / 안 A만 / 안 C(원정 화면의 장부 줄).
11. 대사 초안 여섯(`data/DialogueLineData.csv`. 승인되면 Design/33에 새 절로 【확정】하고 그다음 데이터): **이대로 출발값** / 고칠 줄을 지정.
    - 첫 로비: (기본) "장부의 첫 줄은 광산 마을입니다. 무너진 갱의 광부들이 구덩이에 떨어졌습니다." → (차가움) "당신은 갈 수 없지요. 그 손목으로는." → (기본) "칼을 사세요. 역마차에 떠돌이들이 와 있습니다. 성문을 나서면 광산입니다."
    - 심연이 열린 뒤: (차가움) "광산 마을의 종이 돌아왔습니다. 장부의 한 줄을 지웁니다." → (기본) "다음 장은… 심연. 왕이 구덩이로 달아났다는 소문입니다." → (웃음) "겁이 많은 사람이니까요."
12. 대화를 들은 기록: **`run.json`의 `SeenDialogues`(런 버전 28). 새 런마다 다시 듣는다** / 설정에(한 번 들으면 다시 없음).
13. 옛 런(27): **모두 들은 것으로 올림**(진행 중인 런에 대화가 끼어들지 않음) / 비움(이어하면 첫 로비의 대화가 나옴).
14. 콘티 그림의 파일: **생성 원본 PNG(장당 4~5MB, 열넷 약 60MB, LFS)**(본 그림도 같은 형식, 배선 규칙 그대로) / JPG(약 7MB. 그림 경로 규칙에 확장자 예외가 생김).
15. 단계: **Roadmap 55단계, Slice D 안에** / 새 Slice.

## 판정

- 인트로의 연출은 Round 98의 움직임 목업(`98-intro-storyboard/make_motion.py`)으로 바꿨다. 이 라운드의 인트로 MP4(`intro-*.mp4`)는 거둔 안이다. 그 연출은 데이터의 열(`CameraFrom`·`CameraTo`·`Effect`·`Transition`)과 화면의 계산(`IntroTimeline`)으로 옮겼다. 카메라 값은 그 스크립트의 `CAMERA` 그대로, 짧은 판의 길이는 그 `SHORT_SECONDS` 그대로다.
