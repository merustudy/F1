- **클래시 오브 클랜**(Supercell): 건물마다 레벨별 그림이 따로 있고 레벨이 오르면 더 크고 장식이 는다. 업그레이드를 누르면 금(엘릭서)을 내고 **공사 시간**이 돌며, 그동안 건물 위에 비계·망치질과 남은 시간이 보인다. 일꾼(Builder) 수만큼만 동시에 짓고, 공사 중인 건물은 대개 제 기능을 하지 못한다. [Buildings](https://clashofclans.fandom.com/wiki/Buildings), [Builder](https://clashofclans.fandom.com/wiki/Builder%27s_Hut)
- **다키스트 던전**(Hamlet): 건물의 업그레이드는 창 안의 나무(Deeds·Crests로 산다)이고 즉시 적용된다. 마을의 그림은 바뀌지 않는다. [Hamlet](https://darkestdungeon.wiki.gg/wiki/Hamlet)
- 우리가 가져오는 것: 코클의 **레벨별 그림과 공사 중 표시·소요 시간**. 가져오지 않는 것: 일꾼·보석·자원 종류(재화는 금 하나), 그림 위의 끌어 놓기.
