## 방법에서 남긴 것 (처음부터 다시 할 때 쓸 것)

- 시험 세트 방식(`Archive/<round>/<style>/`에 스타일 문서·소재·기준 그림, `--style/--roster/--reference`)은 그대로 쓰면 된다. 코드는 바꾸지 않았다. 사용자가 올린 기준 그림은 `--reference`로 그대로 붙는다.
- **우리 그림을 기준 그림으로 붙이고 글로 그림체를 바꾸는 방식이 먹혔다.** 매체를 바꿔도(수채, 판화), 얼굴만 바꿔도 몸과 정체가 유지됐다. 두 끝을 한 장에 나란히 붙인 합성 기준 그림도 한 인물만 나왔다.
- 등신은 글로 잘 따라왔다(2.5 → 4 → 4.5 → 5 → 5.5). 폭이 넓은 자세와 큰 도끼는 3:4 캔버스에서 키를 줄인다(최대 8%). 채택 뒤에는 `Height`나 캔버스로 맞춘다.
- 작품 이름은 프롬프트에 넣지 않고 특징을 풀어 쓴다(규칙). 풀어 쓴 특징만으로도 그 느낌이 나온다.
- **지시의 낱말을 생성 전에 되묻는다.** "화풍"을 매체로 읽어 다섯 장(약 $0.12)을 헛돌렸다. 범위가 애매하면 세트를 만들기 전에 한 줄로 확인한다.
- 판정에 쓰는 시트: 전신(게임 표시 크기 + 원본)에 더해 머리 확대 띠가 얼굴 비교에 유용했다(`review_sheet.py`에는 없고 Pillow로 따로 만들었다).
