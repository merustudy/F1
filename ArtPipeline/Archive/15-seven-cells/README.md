# Round 15 — 아이템 칸: 최대 7칸, 칸을 조금 높게, 패널 높이는 그대로 — B안 구현됨

사용자 지시 (2026-10-04): "현재 아이템 칸을 최대 7칸으로 줄이고 아이템 1칸의 세로길이를 좀 길게 해보자. 밑의 UI 높이는 유지하면서. 목업 이미지 제공."

지금 전투 스크린샷(`Archive/14-ui-diablo/game/ko_05_battle.png`) 위에 게임의 Sprite(`slot`, `bag`)와 아이템 아이콘으로 보드를 다시 그렸다(`mock_seven_cells.py`, 호출 없음).
안마다 다른 것은 기하뿐이다. 패널은 모든 안에서 460(위에서 620) 그대로다.

## 지금의 셈

- 패널 460 = 열 위아래 여백 16·16 + 보드 428. 보드 428 = 8칸 x 50 + 7 간격 x 4 (`UiPrefabSetup.Battle`의 `BoardColumnsTop`, `BattleItemView.CellHeight`·`CellGapY`).
- 최대 칸을 7로 줄이면 같은 428~432 안에서 칸 하나가 56~60으로 커질 수 있다. 칸의 폭 180은 무대 열의 폭이라 그대로다.

- 목업의 맨 오른쪽 아군 열(1열)은 **최대 칸을 채운 예**다(지금은 모든 직업이 5칸이고 느는 일이 없다 — Design/02 §4의 【미결】). 나머지 아군은 지금의 5칸.
  장궁(2칸)과 미늘창(3칸)은 큰 아이템의 모양을 보이는 예다.
- 아이콘은 칸의 **폭**에 맞춰 놓이므로(1칸 아이콘 328x80, 4.1:1), 칸이 높아져도 아이콘의 크기는 그대로이고 위아래 여백만 는다(A안: 4px씩).
  아이콘까지 높은 칸에 맞춰 키우려면 스물한 개를 새 칸 캔버스로 다시 그려야 한다(호출 21회, 약 $0.5. 요청이 있을 때만).
