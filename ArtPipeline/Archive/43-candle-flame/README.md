## 권장: A3 (+ C의 외곽선 2)

- 바란 것은 "더 자연스럽게 불타는 것"과 "얇은 외곽선"이다. A3은 둘 다 되면서 호출이 없고 승인된 불꽃의 색·질감을 지킨다. 프레임을 만드는 규칙(휘기·늘이기)이 스크립트라 다섯 장면이 **한 그림에서 나온 듯 고르다**.
- A2는 "촛불 모양"으로 바꾸고 싶을 때의 안이다(권장 다음). A1은 새 그림체의 불꽃을 원할 때, 승인 라운드로.
- 외곽선 2(화면 1px)는 유닛(평균 2.2px)과 UI 틀(2px)보다 얇지만, 불꽃은 작고 빛나는 것이라 가늘어도 된다(배경과 구별은 뒤의 빛이 한다).
