# Docs/Design — 기획문서 안내 (v0-recon, 2026-09-30)

## 이 폴더는 무엇인가
- 이 게임(용병 파티 · 100일 로그라이트)의 기획문서. **Architecture Authority가 아니다.** 구조·폴더·Manager 구성은 Docs/Architecture 에서 정한다.
- ⚠️ 원본 기획문서(v0.5.x)와 `prototype_data.json`에 접근하지 못한 상태에서, 기록된 확정 결정을 원본 구조대로 **재구성**한 것이다. 원본에만 있던 세부 수치·규칙은 【원본확인】으로 비워 두었다.
- 【확정】 (2026-09-30 결정) 원본(기획 v0.5.x, `prototype_data.json`, `sim.py`, `build_data.py`, `lobby_sim`)은 없다. 되찾지 않고 **규칙을 다시 정한다.** 시뮬도 새로 만든다.

## 태그 규칙 — 구조 결정에 쓸 수 있는 것은 【확정】뿐

| 태그 | 의미 | 구조 결정 근거로 |
|---|---|---|
| 【확정】 | 기록된 확정 결정 | 사용 가능 |
| 【검토】 | 검토 중 (미확정) | 불가 |
| 【미결】 | 열린 설계 항목 — 구현 중 임의 해결 금지 | 불가, 질문 목록으로 |
| 【원본확인】 | 원본에 있었으나 재구성본에 없음. 원본이 없으므로 **재정의 대상**이다 | 불가, 추측 금지. 선택지 제안 → 승인되면 【확정】으로 바꾼다 |
| 【해석】 | 기록된 사실로부터의 해석 | 불가, 확인 필요 |
| 【제안】 | 재구성하면서 새로 낸 제안, 또는 재정의를 위한 선택지 | 불가, SJ 승인 전 |

## 수치와 시뮬 결론의 지위 (2026-09-30 결정)
- 이 폴더의 수치(【확정】 포함)와 시뮬 결론(승률, 절벽)은 없어진 원본 규칙에서 검증된 값이다. 규칙을 다시 정하므로, 새 시뮬로 재검증하기 전까지는 **출발값과 목표**로만 쓴다.
- 구조에 관한 【확정】(작은 파티, 5지역, 100일, 쿨다운 오토 전투, 결정론, 아이템 ≠ 유물 등)은 그대로 유효하다.
- 구현 전이라 기획은 크게 바뀔 수 있다. 바뀌면 이 폴더를 먼저 고친다.

## 열 개정 (2026-09-30, 사용자 결정)
플레이해 본 뒤 사용자가 전열/후열을 없애고 열을 다시 정했다. 처음에는 1열/2열/3열로, 이어서 1열~4열과 "한 열에 한 유닛"으로,
그다음 날(2026-10-01) 용병도 4열까지(4인 파티)로 바꿨다.
아래는 지금의 규칙이다. 사용자가 직접 정한 것은 `【확정】 (열 개정)`, "나머지는 권장안대로", "잘못된 부분이 있으면 권장안으로 구현"으로 맡긴
세부는 `【확정】 (열 개정 권장안)`으로 적었다. 뒤쪽은 검토 대상이다.

사용자가 정한 것:

| 결정 | 문서 위치 |
|---|---|
| 열은 1열부터 4열까지다 | 02 §2 |
| 한 열에 한 유닛이다. 파티도 적 무리도 그렇다 | 02 §2, 03 §4, 04 §6 |
| 용병도 4열까지 선다: 파티는 4인까지다(`PartySize`) | 02 §2, 04 §6, 01 §4 |
| 앞 열이 비면 뒤 열이 한 칸씩 전진한다 | 02 §2 |
| 아이템마다 쓸 수 있는 열이 있다 | 02 §4 |
| 공격 범위는 앞에서 세거나 뒤에서 세어 "몇 번째까지 맞는가"로 정한다 | 02 §2 |
| 이전 저장 파일(전열/후열 때의 것)은 읽지 않는다 | `Docs/Architecture/07_SAVE.md` |

권장안으로 정한 세부 (검토 대상):

| 세부 | 문서 위치 |
|---|---|
| 4인 파티에 맞춘 적 무리: 보스가 아닌 무리는 셋이나 넷, 보스 무리는 셋(보스와 그 뒤의 둘) | `EnemyGroupData.csv`, 시뮬 결과는 08 §7 |
| 살아 있는 적이 깊이보다 적으면 있는 만큼만 맞힌다. 적 전부를 맞히는 범위는 따로 둔다 | 02 §2 |
| 쓸 수 있는 열은 서 있는 열의 번호로 정한다(앞/뒤에서 세는 것은 맞는 쪽뿐이다) | 02 §4 |
| 전진이 적용되는 곳(편성, 전투 중의 죽음, 전투 뒤), 빈사 상태는 자리를 지킨다 | 02 §2 |
| 전진과 죽음의 처리 순서, 타깃을 고르는 시점, 여럿을 맞힐 때의 순서 | 02 §2, §3 |
| 쓸 수 있는 열에 들어오거나 벗어날 때의 쿨다운 | 02 §4 |
| 패시브의 열 조건과 판정 시점 | 02 §7 |
| 전투 사이의 자리 바꾸기, 자리가 다음 전투로 이어지는 것 | 03 §5, §6 |
| 로비에서 파티에 넣고 빼고 옮기는 규칙 | 04 §6 |
| 아이템별 쓸 수 있는 열과 공격 범위, 직업의 권장 열과 패시브 열, 적 무리의 구성, 새 아이템 둘(`spear`, `halberd`), 보스 HP | `Assets/@Data/Source/*.csv`, 시뮬 결과는 08 §6(3인), §7(4인) |
