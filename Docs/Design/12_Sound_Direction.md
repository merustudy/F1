# 소리 방향

> 【확정】 (2026-10-05, 사용자 "모두 권장안대로") 결정 관문 G11(소리 방향)의 결정이다. 바꿀 때는 이 문서를 먼저 고친다.
> 소리를 만들고 게임에 넣고 재생하는 기술 규칙은 `Docs/Architecture/14_SOUND.md`가 가진다. 수치(음량의 단계, 겹침의 간격)도 그 문서와 코드가 가진다.

## 1. 방향

【확정】 (2026-10-05) **A. 어두운 카툰.**

- **효과음**: 쇠·나무·가죽·뼈·돌 같은 실제 재료의 묵직하고 마른 소리. 그림이 과장된 만큼 타격감을 살짝 부풀린다. 울림은 짧게 둔다(던전이지만 소리가 뭉개지지 않게).
- **배경음**: 작은 편성(낮은 현, 어쿠스틱 기타, 낮은 목관, 손 타악)의 단조 곡. 어둡지만 약간 익살스럽다. 반복해 들어도 덜 지치게 앞에 나서는 선율을 두지 않는다.
- **밝은 소리는 쓰지 않는다**: 장난감 같은 소리, 장조의 경쾌한 곡. 이전 프로젝트(C1)에서 밝은 배경음이 어두운 화면과 어긋나 세 곡을 다시 만들었다(`Docs/StarterKit/tools/gen_bgm.py`의 기록).
- 근거: 확정된 그림체(10 §2: 손으로 그린 잉크선과 과장, 낮은 채도)와 디아블로 컨셉 UI·촛불이 비추는 무대(10 §4, §5) 양쪽에 맞는다.

레퍼런스. 소리를 만드는 방식만 빌린다. 게임·스튜디오·작곡가의 이름은 생성 문구에 넣지 않는다.

| 게임 | 빌리는 것 |
|---|---|
| Don't Starve (Klei Entertainment) | 손그림 잉크선의 어두운 그림체에 붙은, 어둡고 익살스러운 음악 |
| Diablo (Blizzard North, 1996) | 기타가 중심인 어두운 마을 음악 (로비의 곡) |
| Darkest Dungeon (Red Hook Studios) | 타격과 던전의 무게 (효과음) |

채택하지 않은 안 (2026-10-05에 비교했다):

- B. 정통 다크 판타지(사실적인 칼·갑옷 타격, 던전의 울림, 오케스트라·합창): 무게감은 있지만 캐리커처 그림과 어긋날 수 있고, 큰 편성은 생성 품질의 편차가 크고 반복해 들으면 쉽게 지친다.
- C. 환경음 중심(음악은 로비에만, 던전은 광산의 바람·물방울·먼 곡괭이 소리): 가장 싸고 덜 지치지만 게임의 개성과 보스전의 고조가 약하다.

## 2. 무엇에 소리가 나는가

【확정】 (2026-10-05) Slice A는 효과음 스물여섯과 배경음 세 곡이다.

- **화면에 이미 보이는 사건에 소리를 붙인다.** 소리로만 알려 주는 정보는 없다. 소리를 끄고도 플레이할 수 있다.
- **용병의 죽음이 가장 무겁다.** 영구 손실이 이 게임의 핵심 축이다(01 §5). 적의 쓰러짐과 결정타보다 무겁고 길다.
- **결정타**(10 §5)는 적의 쓰러짐보다 크고, 0.5초의 느림을 채운다.
- 아이템이 발동할 때의 소리는 아이템마다가 아니라 **분류마다 하나**다(02 §4의 분류 가운데 출고 데이터에 있는 무기, 방어, 공격, 지원). 화면의 움직임도 분류마다 같다(10 §5).
  활 시위나 마법처럼 아이템마다 다른 소리는 플레이해 보고 정한다.

| 묶음 | 소리 |
|---|---|
| 아이템 발동 | 무기, 방어, 공격, 지원 |
| 맞음 | 피격, 큰 피격(최대 HP의 20% 이상: 큰 숫자와 흔들림이 나는 때), 보호막에 다 막힘 |
| 상태 | 회복, 보호막 얻음, 불붙음(화상), 빈사, 버텼다(사망 굴림에서 삶) |
| 쓰러짐 | 적의 쓰러짐, 결정타, 용병의 죽음 |
| 전투의 사건 | 포션, 후퇴 성공, 후퇴 실패, 양초가 꺼짐(폭풍이 옴), 번개(폭풍의 틱), 승리, 패배 |
| 화면 | 버튼, 아이템 넣기, 노드 이동, 원정 출발 |

| 곡 | 언제 |
|---|---|
| 로비 | 타이틀, 로비, 귀환 정산 |
| 던전 | 노드 맵, 보상, 보스가 아닌 전투 |
| 보스 | 보스전 |

- 곡은 끊김 없이 반복된다. 화면이 바뀌어도 같은 곡이면 이어서 흐른다.

## 3. 음량

【확정】 (2026-10-05) 플레이어는 음악과 효과음의 크기를 따로 정한다: **켬, 작게, 끔**. 처음에는 둘 다 켬이다. 타이틀 화면의 설정 줄(목업 안 2)에서 바꾸고, 다음에 켜도 남는다.
화면의 자리는 `Docs/Architecture/12_UI.md`가, 저장은 `Docs/Architecture/07_SAVE.md`가 가진다. 설정 화면은 여전히 범위 밖이다.

## 4. 정하지 않은 것 【미결】

그 종류를 처음 만들 때 선택지를 제안하고 승인받는다.

- 아이템마다·적마다 다른 소리 (적의 울음 포함)
- 던전마다 다른 곡 (다른 던전을 만들 때)
- 광산의 환경음
- 전투 밖의 연출 소리 (화면 전환, 로비·정산의 연출)
- 음성 (대사, 내레이션)
