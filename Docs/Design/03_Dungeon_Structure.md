# 던전 구조 설계 (v0-recon, 2026-09-30 재정의)

> `【확정】 (일괄)`은 2026-09-30 일괄 승인으로 다시 정한 Slice A 규칙이다. 수치는 `Assets/@Data/Source/*.csv`가 가진다.

## 1. 구조
- 【확정】 Slay the Spire식 **노드 구조**
- 【확정】 **5개 지역**
- 【확정】 (일괄) 던전은 층으로 이루어진다. 전투 층이 `Floors`개 있고 마지막에 보스 층이 하나 있다.
- 【확정】 (일괄) 전투 층마다 노드가 `MapMinWidth`~`MapMaxWidth`개 있다. 각 노드는 다음 층의 가까운 노드 하나 또는 둘로 이어진다.
  모든 노드는 들어오는 길과 나가는 길이 하나 이상 있다. 보스 노드는 하나이고 마지막 전투 층의 모든 노드에서 이어진다.
- 【확정】 (일괄) 맵은 원정 시드로 만든다. 같은 시드는 같은 맵이다.
- 【확정】 (일괄) 첫 층에서는 아무 노드나 고른다. 그 뒤로는 지금 노드에서 이어진 노드만 고른다. 되돌아가지 않는다.
- 【확정】 (일괄) 노드 종류는 **전투**와 **보스** 둘이다.
- 【원본확인】 상점·이벤트 같은 다른 노드 종류, 지역 해금 순서 (Slice A 밖)

## 2. 던전 길이와 피로도
- 【확정】 짧은 던전 피로도 비용 **30** (40 / 75 변형은 시뮬로 기각)
- 【확정】 (일괄) 던전마다 피로도 비용(`FatigueCost`)과 걸리는 일수(`DurationDays`)가 있다 (`DungeonData.csv`).
- 【원본확인】 다른 던전 길이 (Slice A 밖)

## 3. 지역 속성 (affinity)
- 【확정】 5종: `swift` / `hardened` / `regen` / `warded` / `armored`
- 【확정】 역할: 파티 구성 유도 → **난이도 수정자**로 재정의
  - 이유: 시뮬 결과, 속성과 무관하게 전열 전사가 필수 → 구성 유도 목적 실패
- 【확정】 swift −8%, hardened −15% (값 상세 → 02_Combat_System §8)
- 【확정】 (일괄) 던전은 속성 하나를 가진다(`AffinityId`). Slice A의 던전은 `swift`다.
- 【원본확인】 나머지 지역과 속성의 배정

## 4. 적과 보스
- 【확정】 보스 레벨: B = **9**, C = **13** (속성 재보정 후 상향)
- 【확정】 적 레벨 **14는 최종 보스 전용**
  - 이유: Lv14가 아이템 등급 상승 임계를 넘어 사망 ×5
- 【확정】 (일괄) 적은 `EnemyData.csv`가 정한다: 최대 HP, 레벨, 아이템과 등급. 적의 아이템은 용병의 아이템과 같은 규칙으로 움직인다.
- 【확정】 (일괄) 적 무리는 `EnemyGroupData.csv`가 정한다: 어느 던전의 몇 층에 나오는지, 전열과 후열에 누가 서는지.
  전투 노드는 그 층에 나올 수 있는 무리 중 하나를 맵 난수로 고른다. 보스 노드는 그 던전의 보스 무리다.
- 【확정】 (일괄) Slice A의 보스는 레벨 9다.
- 【원본확인】 보스 A 레벨, 지역별 적 레벨 곡선
- 최종 보스 → 02_Combat_System §9

## 5. 아이템 흐름
- 【확정】 던전 종료 시 아이템 전부 소멸
- 【확정】 (일괄) 원정을 떠날 때 용병은 직업의 기본 무기만 가진다.
- 【확정】 (일괄) 보스가 아닌 전투에서 이기면 **보상** `RewardChoices`개 중 하나를 고르거나 넘긴다. 보상은 아이템이나 포션이다.
  아이템의 등급은 던전과 층이 정한다(`ItemGradeBase` + 층 × `ItemGradePerFloor`). 후보는 보상 난수로 뽑는다.
- 【확정】 (일괄) 고른 아이템은 용병 하나의 칸에 넣는다. 찬 칸에 넣으면 원래 아이템은 없어진다. 포션은 빈 포션 칸이 있을 때만 받을 수 있다.
- 【확정】 (일괄) 전투 사이에는 두 칸의 아이템을 서로 바꾸거나 옮길 수 있고, 용병의 열을 바꿀 수 있다.

## 6. 전투 사이에 이어지는 상태
- 【확정】 (일괄) HP는 다음 전투로 이어진다. 보호막, 화상, 쿨다운 진행은 전투마다 처음부터다.
- 【확정】 (일괄) DoG 상태로 전투를 마친 용병은 다음 전투를 HP 0보다 큰 상태로 시작한다(승리 후 회복을 받는다 → 02_Combat_System §12).

## 7. 원정의 끝
- 【확정】 (일괄) 보스를 이기면 **클리어**, 파티가 모두 죽으면 **전멸**, 후퇴에 성공하면 **후퇴**다.
- 어느 경우든 귀환 정산을 거친다 (→ 04_Lobby_100Day_Economy §9).
