## 2. 시간
- 【확정】 총 100일 (`TotalDays`)
- 【확정】 (일괄) 런은 1일차에 시작한다. 원정을 다녀오면 그 던전의 `DurationDays`만큼, 쉬면 `RestDays`만큼 날이 간다.

  → 【확정】 (Slice C, 2026-10-16 사용자 결정 1) **100일을 넘으면 강제 최종 결전**이다. 기한을 넘기는 것 자체는 패배가 아니다. 출발은 막지 않는다(남은 날이 던전의 일수보다 적어도 간다).

  → (25단계 구현) `RunRules.IsFinalStandDue`·`CanRest`·`CanDepart`(다른 던전은 `FinalStandDue`), 최종 결전의 원정은 `ExpeditionState.FinalStand`(지도가 보스 하나). 저장 13. 로비는 기한을 넘기면 안내 줄이 "최종 결전"이고 쉬기가 꺼진다.
