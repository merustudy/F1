# 34. 효과 중첩의 너프 — 중첩 상한과 가속의 상한 【제안】

2026-10-23 사용자: "가속, 재생, 암흑 등 효과 중첩이 너무 강해서 너프 필요(특히 가속은 상한을 100으로 두는 방안 검토)".
이 문서는 【제안】이다. 판정 전에는 규칙도 데이터도 바꾸지 않는다. 지금 규칙은 02 §5 "일곱 상태"·"효과 어휘"(【확정】)가 가진다.

## 1. 지금 무엇이 강한가 (측정)

측정은 저장소 밖 시뮬 복사본에서 했다. 세는 줄만 더했고 난수는 그대로이며, 끈 상태의 출력은 저장소와 byte 단위로 같다. 표는 광산 원정 1,000번(시드 1, 새 파티)을 센 것이다. 값은 유닛이 상태를 가진 1초마다의 중첩이다.

| 상태 (가진 쪽) | 평균 중첩 | 가장 큰 값 | 10 이상인 시간 |
|---|---|---|---|
| 암흑 (적) | 16.4 | 520 | 44% |
| 빙결 (적) | 14.4 | 356 | 39% |
| 재생 (아군) | 11.3 | 492 | 32% |
| 조준 (아군) | 9.2 | 393 | 29% |
| 예리·격분 (아군) | 7.4 | 280 | 24% |
| 취약 (적) | 7.1 | 142 | 22% |
| 가속 (아군) | 6.5 | 535 | 11% |
| 가속 (적) | 4.5 | 466 | 2% |

- 아군 아이템이 쿨다운을 셀 때 6.7%가 바닥(`MinCooldownMs` 0.2초)에 닿는다. 런에서는 가속이 802중첩까지 간다.
- **까닭은 셋이다.**
  1. 감쇠가 1초에 1뿐이다. 그래서 거는 양이 그보다 빠르면 끝없이 쌓인다.
  2. 단계가 중첩 수를 곱한다(1성 ×2, 2성 ×3, 3성 ×4). 3성 재 주머니는 5초마다 앞의 둘에 암흑 12를 건다. 일반 단계(5초마다 3)는 쌓이지 않는다.
  3. **가속은 되먹임이다.** 지금 식은 쿨다운 × (1 − 0.1 × 중첩)이라 10중첩이면 바닥에 닿는다. 나팔이 빨라지면 가속을 더 자주 걸어 폭주한다. 49단계부터 14층의 고블린 고참이 나팔을 든다(정예 무리 `veteran_guard`에 둘). 2026-10-23의 직접 플레이는 이 띠인 16층 전투에서 파티 넷이 모두 쓰러졌다.
- 화상·출혈은 이번 지시의 바깥이라 재지 않았다.

## 2. 선택지

| 안 | 내용 | 광산 클리어 / 죽음 | 런 균형형 / 안전형 | 가장 큰 중첩 |
|---|---|---|---|---|
| 지금 | — | 64.9% / 0.44 | 90.4 / 96.5 | 무한 |
| **가** | **가속을 '속도'로: 쿨다운 ÷ (1 + 0.1 × 중첩), 빨라짐은 +100%까지(쿨다운이 절반까지)** | 66.4 / 0.39 | 91.6 / 97.5 | 가속만 막힘 |
| 나 | 가속의 지금 식에 빼는 몫만 50%까지 | 64.7 / 0.43 | 91.0 / 96.5 | 가속만 막힘 |
| **다** | **가 + 일곱 상태와 재생의 중첩 상한 10** | **58.9 / 0.48** | **89.1 / 96.2** | 10 |
| 라 | 가 + 상한 15 | 64.2 / 0.42 | 91.2 / 97.5 | 15 |
| 마 | 가 + 상한 5 | 45.6 / 0.65 | 77.8 / 92.4 | 5 |
| 바 | 가 + 단계가 중첩에 주는 몫을 절반으로(×1.5·2·2.5) | 56.6 / 0.51 | 88.2 / 95.8 | 줄지만 무한 |
| 사 | 지속 시간 방식: 중첩은 남은 초, 효과는 크기 하나(슬레이 더 스파이어의 취약·약화처럼) | (재지 않음) | | — |

- 시드 1~3의 평균이다. 광산의 띠는 클리어 50~65%, 죽음 0.3~0.4다. 런은 아직 띠 위에 있다(43단계 2차가 따로 맞춘다).
- 상태는 양쪽에 걸린다. 그래서 가속만 막는 안(가·나)은 적의 폭주(나팔)도 막아 광산이 조금 쉬워진다.
- 상한 10을 두고 감쇠도 그대로이면, 10중첩일 때의 크기는 다음과 같다.
  - 암흑 −50%p, 조준·예리 +50%p, 격분 +250%p
  - 빙결: 쿨다운 두 배
  - 가속: 쿨다운 절반(가의 식에서 10중첩이 곧 +100%)
  - 취약: 받는 피해 +100%
  - 재생: 1초에 2.7 회복
- 다를 적용한 광산 원정: 모든 중첩이 10에서 멈춘다. 10에 머무는 시간은 적의 암흑 16%, 아군의 재생 10%다. 쿨다운 바닥에 닿는 일은 없다.
- 상한에 닿은 뒤 다시 걸면 10으로 채운다(감쇠까지의 시간이 다시 찬다).
  - 3성 재 주머니(12)는 한 번에 상한이다. 1성(6)·2성(9)은 두 번이다.
  - 그래서 단계의 몫은 "얼마나 빨리 상한에 닿고 얼마나 오래 머무나"로 남는다.

## 3. 판정할 것 (권장안은 첫째)

| 3 | 상한의 대상 | **일곱 상태 + 재생**(지시의 셋을 포함) / 화상·출혈도(피해 쪽 — 따로 재고 판정) |
| 4 | 단계와 중첩 | **그대로(단계가 곱함)** / 단계의 몫 절반(안 바) |

| 6 | 화면 | **상태 칩의 숫자는 그대로, 상한이면 칩에 테(목업 먼저)** / 바꾸지 않음 / 카드 문구에 "최대 10" |
| 7 | 순서 | **이 너프를 먼저, 43단계 2차의 군주 HP는 그 위에서 다시**(아래) / 43단계 2차 먼저 |

- 7의 측정(다의 위, 여섯 시드): 43단계 2차의 권장 묶음 "군주 610 + 광산 7일 + 심연 4일"은 다음과 같다.
  - 균형형 65.0%: 띠의 가장자리다.
  - 사망 한도 11.6%: 띠 12% 바로 아래다.
  - 안전형 75.5%.
  - 군주 580이면 균형형 70.4%, 안전형 80.2%(띠 위)다. 그래서 너프가 들어가면 군주는 590~600 근처로 다시 잰다.

## 3-1. 사용자 판정 (2026-10-23)

사용자는 "쿨다운의 1%를 줄이는 것으로 하자"고 정했다. 가속 1중첩은 −1%(`HastePercentPerStack` 10 → 1)이다. 아직 판정하지 않은 것은 식·상한·나팔의 값이다.

1%로 바꾼 측정(시드 1~3, 저장소 빌드에 데이터만 바꿈):

| 변형 | 광산 클리어 / 죽음 | 런 균형형 / 안전형 | 아군 가속 평균 / 최대 | 쿨다운 바닥 |
|---|---|---|---|---|
| 지금 (10%, 나팔 3) | 64.9% / 0.44 | 90.4 / 96.5 | 6.5 / 535 | 6.7% |
| 1%, 나팔 3 | 67.3 / 0.38 | 92.8 / 97.6 | 8.6 / 271 | 0.1% |
| 1%, 나팔 10 | 62.7 / 0.47 | 89.2 / 96.0 | — | — |
| 1%, 나팔 30 | 52.1 / 0.77 | 78.7 / 88.1 | 90 / 13,332 | 10% |

- 중첩은 세기이면서 남은 초다. 감쇠가 1초에 1이기 때문이다.
  - 나팔을 3 그대로 두면 가속은 "약 3초 동안 −3%"가 되어 거의 일을 하지 않는다. 적의 폭주는 사라진다(적의 가속 최대 6).
  - 나팔을 30으로 올려 세기를 되돌리면 한 번 불 때 30초 동안 가고 다시 폭주한다.
- 그래서 1%로 하려면 나팔의 값과 상한을 함께 정해야 한다.
- **구현**(같은 날 사용자 "가속도 1%로 먼저 구현 후 다른 효과들 보고"): `HastePercentPerStack` 1만 바꿨다. 나팔 3과 빼기 식은 그대로다. 02 §5에 【확정】으로 적었고, 시뮬 전후는 08 §57이다.
- 남은 판정(위 §3의 1~7): 판정 1은 이제 "식을 속도로 바꿀지와 상한"이다. 1%에서는 100중첩이 되어야 바닥에 닿는다. 그 밖에 상한 10/15, 나팔의 값, 단계, 화면, 순서가 남았다.

## 3-2. 사용자 판정과 값의 검토 (2026-10-23 이어서)

- 사용자: "상한은 두지 않는 걸로 적용". **중첩 상한은 없다**. §3의 판정 2·3은 "없음"으로 닫혔고, 지금 규칙 그대로라 바꿀 것이 없다.
- 감쇠(코드 확인): 화상·출혈·재생과 일곱 상태는 모두 같은 1초 틱(`BurnTickMs` 1000, 전투 시작부터의 배수)에 **1씩** 준다. 차례는 화상 → 출혈 → 재생 → 일곱 상태다. 그래서 중첩 N은 세기이면서 남은 초다. 죽으면 0이고, 전투가 끝나면 사라진다.
- 사용자가 검토를 물은 값: 암흑 −1%p, 빙결 +1%, 재생 1 회복, 조준 +1%p, 격분 +5%p, 예리 +1%p, 가속 −1%(지금), 취약 +5%. 데이터만 바꾼 복사본(시드 1~3, 지금 데이터 = 가속 1% 위)으로 쟀다.

| 변형 | 광산 클리어 / 죽음 / 붕괴 | 균형형 / 안전형 |
|---|---|---|
| 지금 | 67.3% / 0.38 / 33.6% | 92.8 / 97.6 |
| 암흑 5 → 1 | 59.8 / 0.47 / 37.4 | 89.7 / 96.9 |
| 빙결 10 → 1 | 66.2 / 0.40 / 34.1 | 92.2 / 97.5 |
| 재생 0.27 → 1 | **70.8 / 0.35** / 33.2 | 93.9 / 98.6 |
| 조준 5 → 1 | 67.3 / 0.38 / 34.0 | 91.7 / 98.1 |
| 격분 25 → 5 | 66.1 / 0.39 / 33.6 | 92.2 / 97.8 |
| 예리 5 → 1 | 65.6 / 0.40 / 36.5 | 92.9 / 97.0 |
| 취약 10 → 5 | 66.7 / 0.39 / 34.6 | 92.0 / 97.6 |
| **모두** | 61.2 / 0.45 / 42.9 | 91.4 / 97.7 |
| 모두, 재생만 0.27 그대로 | 55.6 / 0.52 / 42.2 | 88.2 / 96.4 |

- 읽은 것
  1. **재생 1은 너프가 아니라 약 3.7배의 강화다.** 지금 0.27이 1중첩의 회복이다(전사 HP 30의 약 1%). 아군의 재생은 평균 13중첩이라 1이면 1초에 13 회복이다. 그래서 "모두"의 광산이 재생 그대로인 묶음보다 5.6%p 높다.
  2. 중첩당 값을 낮춰도 상한이 없으니 쌓임은 그대로다. 적의 암흑은 평균 16.9중첩, 최대 463이다. 1%p면 평균 −17%p이고, 30중첩 이상인 15%의 시간은 여전히 −30%p 아래까지 간다. 폭주가 다섯 배 느려질 뿐 사라지지는 않는다.
  3. 하나씩으로는 암흑만 크다(광산 −7.5%p). 나머지는 ±1.5%p 안이다. 상태는 양쪽에 걸리고, 적이 아군에게 거는 암흑·취약도 같이 약해진다.
  4. 붕괴 난 원정이 34 → 43%로 오른다(띠 30~50 안). 붕괴의 문턱은 전투가 길어지는 만큼 닿는다.

## 3-3. 화상·출혈의 변경안과 효과의 순위 (2026-10-23 이어서)

사용자는 "화상 1초에 1피해, 출혈 1초에 1피해 / 화상은 1초에 1개씩 소멸 혹은 정화 소멸 / 출혈은 초가 지나도 자동 소멸 안되나, 치유 1번에 1소멸 혹은 정화 소멸"의 변경 검토를 물었다. 또 "현재 효과의 실제 게임 효과에 따라 순위 보고"와 "현재 효과-변경안이 적용된 효과"를 물었다.
