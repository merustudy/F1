# 유물 시스템 설계 (재구성 v0-recon)

## 1. 정의
- 【확정】 유물 = 로비에 **영구 적용되는 패시브 보너스**
- 【확정】 아이템과 **절대 혼동하지 않는다** (초기의 치명적 정정 사항)

| | 아이템 | 유물 |
|---|---|---|
| 수명 | 던전 안에서만, 종료 시 소멸 | 영구 |
| 작동 | 쿨다운 순환 발동 (능동) | 패시브 |
| 위치 | 전투 보드 슬롯 | 로비 |

## 2. 시작 유물
- 【확정】 **시작 유물 없음**
- 과거에 시작 유물을 넣은 구현은 전체 재밸런싱이 필요했다.

## 3. 조건 판정
- 【확정】 전열/후열 조건은 **실제 파티 위치** 기준 (`Battle.is_front` / `Battle.is_rear`), 직업 권장 열 기준이 아니다.

## 4. 구현 주의
- 【확정】 아이템과 유물은 데이터·코드에서도 분리한다 (1절의 원칙)

## 5. 원본확인
- 유물 목록, 획득 경로, 보유 한도, 중첩 규칙
