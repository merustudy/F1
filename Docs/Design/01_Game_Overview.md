# 게임 개요 (재구성 v0-recon)

## 1. 한 줄 요약
【확정】 용병 파티(4인까지)를 이끌고 **100일 카운트다운** 안에 5개 지역의 던전을 공략하는 로그라이트. 원정 사이에는 로비에서 경영한다.

## 2. 플랫폼
- 【확정】 PC 전용. 모바일은 고려하지 않는다.
- 초기 기록의 "모바일 로그라이트"는 2026-09에 정정됨.
- 【확정】 엔진: Unity (2026-09-30 프로젝트 셋업 지시 기준)

## 4. 코어 루프

```
로비(경영·준비)
  → 원정 출발 (용병 4인까지)
  → 던전 노드 진행 + 오토 전투
  → 귀환 (아이템 소멸)
  → 로비 ... (반복)
  → 100일 안에 최종 보스 격파 = 승리
```

- 【확정】 4인까지의 파티(2026-10-01 열 개정. 그전에는 3인), 5개 지역, 100일, 원정 사이 로비 레이어
- 【확정】 최종 보스 격파가 승리 조건 (lobby_sim 승리 판정 기준 "최종 보스")
- 【해석】 100일 초과 시 패배
- 【원본확인】 귀환 시 보상·성장 반영 방식

## 5. 설계 축

- **영구 손실에 대한 책임** — 【확정】 핵심으로 명시됨 (2026-09)
- **준비가 곧 전투** — 전투는 자동이고, 플레이어의 결정은 편성·배치·아이템 보드에서 나온다. 【해석】
- **아이템과 유물의 엄격한 분리** — 【확정】
- **시뮬레이션 우선 밸런스** — 【확정】 모든 결정은 시뮬로 검증 후 문서화

## 6. 용어

| 용어 | 정의 | 상태 |
|---|---|---|
| 피로도 | 원정에서 쌓이는 용병의 지침(0~200). 100에서 붕괴 판정(고통 또는 각성), 200에서 쓰러짐. 쉬면 내려간다 | 【확정】 "기력"은 폐기, 전부 피로도로 통일. 쌓이는 모델은 2026-10-06 Slice B(그전에는 최대치에서 차감, 04 §3) |
| 아이템 | 전투 카드. 쿨다운으로 순환 발동, 던전 종료 시 소멸. 크기(1~3칸)만큼 보드의 칸을 차지한다. 단계(일반·동·은·금. 2026-10-07에 이름을 바꿈)가 있고 같은 것 둘을 합치면 한 단계 오른다 | 【확정】 (크기는 2026-10-01, 단계와 합치기는 2026-10-06) |
| 정예, 야영지 | 원정 지도의 노드. 정예는 더 어려운 전투와 높은 단계의 보상, 야영지는 쉬기(HP·피로) 또는 정비(아이템 한 단계) | 【확정】 (2026-10-06, 03 §1) |
| 상점, 지역 코인 | 원정 지도의 노드: 싸움 없이 지역 코인으로 아이템을 사고 새로고침한다. 지역 코인은 전투에서 받아 원정 안에서만 쓰는 재화로, 원정이 끝나면 사라진다 | 【확정】 (2026-10-07, 17단계, 03 §1·§5) |
| 인벤토리 | 원정 동안 보드 밖에 두는 아이템 주머니(10×3 격자, 디아블로 2의 인벤토리: 아이템은 자리와 방향을 갖는다). 전투에 쓰이지 않고 귀환하면 사라진다 | 【확정】 (2026-10-01. 용량은 개정 4, 격자는 2026-10-09 Round 49) |
| 유물 | 로비에 영구 적용되는 패시브 보너스 | 【확정】 아이템과 혼동 금지 |
| 지역 속성 | 지역별 난이도 수정자 5종 | 【확정】 |
| Death-or-Glory (DoG) | 사망 여부를 굴리는 판정. 실질적 주 사망 원인 | 세부 【원본확인】 |
| 열 (1열~4열) | 양쪽에 네 열, 한 열에 한 유닛. 1열이 상대와 가장 가깝다. 조건은 실제 파티 위치 기준. 앞 열이 비면 뒤 열이 전진한다 | 【확정】 (2026-09-30에 전열/후열에서 바뀜) |

## 7. 큰 방향의 열린 질문

- 【확정】 (2026-09-30) 소영주·성 경영·공성전 컨셉은 채택하지 않는다. 로비 레이어는 기존 구조를 유지한다.
- 【확정】 (2026-09-30) 대규모 로스터는 채택하지 않는다. 작은 파티 구조를 유지한다(2026-10-01부터 4인까지 → 02 §2).
- 【확정】 (2026-09-30) 전투 중 플레이어 개입(포션/후퇴)을 도입한다. 세부는 【미결】 → 02_Combat_System §10
