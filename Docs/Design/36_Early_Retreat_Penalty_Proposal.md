# 조기 퇴각의 패널티 (【제안】)

2026-10-23 사용자: "일찍 퇴각시 보상 및 경험치, 긍정적 후천적 특성은 “조기에 퇴각하여 아무것도 얻을 수 없었습니다“로 하여 얻지 못하게 하며, 부정적 특성은 얻는 걸로 하자.(조기 퇴각 패널티) 검토 후 보고".

이 문서는 【제안】이다. 판정 전에는 구현하지 않는다.

## 1. 지금 조기 퇴각이 주는 것 (53단계 뒤)

조기 퇴각은 원정의 1/3 전의 후퇴다. 기준은 보스를 넣은 층 수의 `FreeRetreatPercent` 33%이고, 파티가 선 층으로 잰다. 광산은 6층까지다(04 §2). 지금은 시간만 들지 않고 정산은 보통 후퇴와 같다.

| 정산의 것 | 지금 | 근거 |
|---|---|---|
| 금 | 도달한 층 × `GoldPerFloor`(3) | 04 §9, `RunRules.GoldFor` |
| 경험치 | 도달한 층 × `ExpPerFloor` | 05 §2, `LevelRules.ExpFor` |
| 코인·아이템의 금 | 없음(클리어만) | 04 §5 |
| 얻은 특성 | 출처마다 한 번 굴림: 후퇴(패배의 기억 −, 15%), 빈사(절뚝임 −·흉터 −·구사일생 +, 25%), 정신 붕괴(악몽 −, 40%), 각성(단련 +, 40%) | 05 §6, `TraitRules.SourcesOf` |
| 죽음·피로 | 그대로 남음 | CLAUDE.md §6 |

- 긍정 특성 중 조기 퇴각에서 나올 수 있는 것은 **구사일생**(빈사)과 **단련**(각성) 둘이다. 노련함은 클리어에서만 나온다.
- 부정 특성은 넷 다 나올 수 있다: 패배의 기억, 절뚝임, 흉터, 악몽.

## 2. 제안

- **잃는 것**: 금, 경험치, 긍정 특성(구사일생·단련). 사용자 지시 그대로다.
- **남는 것**: 부정 특성(패배의 기억·절뚝임·흉터·악몽), 죽음, 피로.
- **시간**: 53단계대로 0주.
- **정산 화면**: 금 줄 자리에 "조기에 퇴각하여 아무것도 얻을 수 없었습니다"를 쓴다. 경험치 줄은 비운다. 부정 특성이 나왔으면 그 줄은 평소처럼 아래에 보인다.
- **판별**: 화면은 정산 보고의 `DaysPassed == 0`이고 결과가 후퇴인 것으로 안다. 새 필드가 없으니 저장 형식도 그대로(27)다.

## 3. 시뮬 (저장소 밖 복사본, 런 300 × 시드 1~6, 53단계 위)

| | 패널티 없음 (지금) | 패널티 |
|---|---|---|
| 균형형 승리 / 전멸 / 한도 | 64.5 / 27.5 / 8.0 | 62.7 / 31.6 / 5.7 |
| 균형형 고용 / 끝난 금 | 5.1 / 83.7 | 4.8 / 80.8 |
| 안전형 승리 / 전멸 / 한도 | 78.6 / 13.5 / 8.0 | 75.0 / 21.7 / 3.4 |
| 조기 퇴각 / 원정 | 균형형 13.6%·안전형 22.7%(평균 도달 2.2층·1.5층) | 같은 정도 |
| 잃은 긍정 특성 | — | 런 3,600에 447번(구사일생·단련) |

- 시뮬의 정책은 다쳤을 때만 후퇴한다. 그래서 일찍 무너진 원정이 조기 퇴각이 된다. 한 번에 잃는 것은 작다(금 약 6, 경험치 약 2).
- 그래도 전멸이 오른다(균형형 +4.1%p, 안전형 +8.2%p). 금이 줄어 고용이 줄고, 로스터가 얇아져 무너지는 런이 는다.
- 사망 한도 패배는 내려간다. 같은 런이 한도보다 전멸로 먼저 끝나기 때문이다.
- 런 띠는 53단계부터 이미 밖이고, 사용자 지시로 심연과 함께 나중에 맞춘다. 이 패널티는 그 자리를 조금 더 어렵게 옮긴다.
- 좋은 점: 53단계의 빈 곳이 닫힌다. 6층까지 돌고 돌아와 시간 없이 금·경험치를 버는 반복이 없어진다.

## 4. 판정할 것 (권장안은 첫째)

| # | 무엇 | 선택지 |
|---|---|---|
| 1 | 잃는 것 | **금·경험치·긍정 특성**(지시) / 경험치는 남김 |
| 2 | 부정 특성의 굴림 | **평소처럼 굴리고 나온 긍정을 버림**: 부정이 나올 확률은 보통 후퇴와 같다(빈사 25% 중 2/3) / 긍정을 뺀 풀에서 굴림: 빈사의 부정이 25%로 오른다(더 셈) |
| 3 | 기준 | **시간의 기준과 같은 하나의 선**(1/3, 광산 6층까지) / 따로 둠 |
| 4 | 정산 화면 | **금 줄 자리에 문구, 경험치 줄은 비움, 제목은 "후퇴" 그대로**. 배치가 그대로라 목업 없이 구현하고 스크린샷으로 대조한다 / 제목도 "조기 퇴각"으로 / 목업 먼저 |
| 5 | 후퇴 단추의 경고 | **다음 화면 라운드에서 목업 먼저**: "지금 후퇴하면 아무것도 얻지 못한다(시간도 들지 않음)". 패널티가 생기면 1/3의 선이 보여야 한다 / 넣지 않음 |
| 6 | 저장 | **그대로**(보고의 `DaysPassed`와 결과로 판별) / 보고에 조기 퇴각 필드를 더함(저장 28) |
| 7 | 시뮬의 런 띠 | **그대로 둠**(심연과 함께 나중) / 지금 다시 맞춤 |
