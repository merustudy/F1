## 1. 한 문장으로

**너희는 전쟁이 끝나 일자리를 잃은 용병들이다. 한 영주가 100일 동안 일 다섯 가지를 맡긴다. 그 다섯 가지 일이 훗날 사람들이 아는 유명한 동화 다섯 편의 "진짜 이야기"다.**

비유하면, 우리가 아는 동화는 **잘못 전해진 소문**이고 게임은 **실제로 있었던 일**이다. 플레이어는 동화의 뒷이야기를 직접 겪는다.

## 2. 다섯 줄 줄거리

1. 전쟁이 끝났다. 용병들은 세 푼 받고 쫓겨났다.
2. 전쟁 영웅 출신의 영주가 일자리를 낸다. 100일 안에 일 다섯 가지. 기한은 영주의 결혼식 날이다.
3. 일을 하나 끝낼 때마다, 그 일 뒤에 숨은 **영주의 나쁜 짓**이 하나씩 드러난다. 맡긴 일은 사실 영주가 저지른 일의 뒷정리였다.
4. 다섯째 일은 영주 자신이다. 그가 동화 「푸른 수염」의 그 영주다. 결혼식 날까지 그의 성에 쳐들어가 쓰러뜨린다.
5. 훗날 사람들은 이 일들을 동화로 전했다. 동화 속에서 용병은 사냥꾼, 왕자, 오빠로 바뀌거나 사라졌다. 그래서 용병단의 기록자 야코프가 진짜를 적는다. 결말에서 동화책 여백에 **"우리였다"**와 이번 런 용병들의 이름이 남는다.

## 3. 처음 설명이 어려웠던 까닭

| 어려웠던 점 | 고친 방향 |
|---|---|
| 인트로가 "세 동화의 단어를 지우는 장면"부터 시작해, 우리가 누구인지 알기 전에 알 수 없는 장면을 봤다 | **시간 순서대로**: 우리는 누구 → 무슨 일 → 그 일이 동화가 된다 |
| "지금"과 "백 년 뒤"가 처음부터 섞였다 | "백 년 뒤"는 쓰지 않고 "훗날"로 한 번만 말한다 |
| 이름이 한꺼번에 셋(야코프, 티모, 영주) | 인트로에서 이름이 나오는 것은 야코프 하나뿐이다 |
| 동화를 고쳐 쓰는 예가 셋이었다 | 예는 **하나**(백설공주의 사냥꾼)만 든다 |
| 계약 조항 다섯과 동화의 관계가 안 보였다 | 던전마다 "동화에서는 / 실제로는"을 같은 틀로 보인다(§4) |

## 4. 큰 구성

### 흐름

```
시작   전쟁이 끝나 일자리를 잃었다 → 영주의 100일 계약(일 다섯)
1막    굶주린 숲            (헨젤과 그레텔)        마녀를 없앤다       → 영주가 곡식을 숨겼다
2막    일곱 광부의 광산      (백설공주)            고블린을 쫓는다     → 영주가 상속녀를 노린다
3막    춤추는 마을          (열두 공주의 춤)       마을을 조용히 시킨다 → 영주가 곰팡이 핀 곡식을 팔았다
4막    잠든 성              (잠자는 숲속의 공주)   성문을 연다         → 영주가 밖에서 문을 잠갔다
5막    푸른 수염의 성        (푸른 수염)           결혼식 날까지        → 영주가 최종 보스
끝     동화에는 "오빠들이 구했다" → 여백에 "우리였다"와 이름들
```

### 영주의 속셈 (한 장)

영주는 **땅과 돈**을 위해 나쁜 짓을 했다. 그리고 그 흔적을 치우려고, 사정을 모르는 떠돌이 용병을 고용했다. 일마다 다른 용병단을 쓰면 아무도 전체를 모른다. 그런데 너희는 다섯 가지 일을 모두 했다. 그래서 전체가 보인다.

| 영주가 맡긴 일 | 영주의 진짜 속셈 |
|---|---|
| 숲의 마녀를 없애라 | 숲에 숨겨 둔 곡식 창고를 몰래 옮기고 싶다(기근은 그가 곡식을 쌓아 둔 탓이다) |
| 광산의 고블린을 쫓아내라 | 광산에 숨은 의붓딸(땅을 물려받을 사람)까지 함께 치워 주기를 바란다 |
| 춤추는 마을을 조용히 시켜라 | 곰팡이 핀 곡식을 판 것이 알려지지 않게 입을 막고 싶다 |
| 잠든 성의 문을 열어라 | 역병 때 자기가 밖에서 잠근 성의 보물과 땅문서를 증인 없이 꺼내고 싶다 |
| 결혼식 날까지 모두 마쳐라 | 일곱째 아내(2막의 그 의붓딸)와 결혼해 땅을 차지하고, 일을 끝낸 용병들도 치울 셈이다 |

### 던전 다섯

모든 던전을 같은 틀로 적는다. **동화에서는 / 실제로는 / 맡은 일 / 싸우는 적 / 보스 / 기믹 / 끝나면 알게 되는 것.**
기믹 칸의 표시: **[지금 규칙]**은 데이터만 바꾸면 되는 것, **[새 규칙]**은 규칙을 새로 정해야 하는 것(시뮬 먼저)이다.

#### 1막 — 굶주린 숲 (헨젤과 그레텔)

| | |
|---|---|
| 동화에서는 | 버려진 오누이가 과자 집 마녀를 오븐에 밀어 넣었다 |
| 실제로는 | 흉년에 버려진 아이들을 숲 마녀(진짜 괴물)가 잡아먹고 있었다. 오븐 문을 붙든 것은 용병단의 궁수였다 |
| 맡은 일 | 숲의 마녀를 없애라 |
| 적 | 굶주린 늑대(출혈), 까마귀 떼, 과자 집의 생강빵 골렘 |
| 보스 | 숲 마녀. 오븐의 불(화상)을 쓴다 |
| 기믹 | **굶주림: 쉴 곳이 드물다.** 이 숲에는 야영지가 적게 나온다 [지금 규칙: 던전 데이터의 야영지 확률]. HP와 포션을 아껴야 한다 |
| (선택) | **빵 부스러기**: 지나온 길이 새에게 쪼여 지도에서 지워진다. 보이는 것만 바뀌고 규칙은 지금과 같다(지금도 되돌아갈 수 없다) |
| 끝나면 | 마녀의 집 아래에서 **영주의 문장이 찍힌 곡식 자루**가 나온다. 기근은 영주 탓이었다 |

#### 2막 — 일곱 광부의 광산 (백설공주)

| | |
|---|---|
| 동화에서는 | 일곱 난쟁이가 공주를 숨겨 주었고, 사냥꾼은 공주를 차마 죽이지 못하고 살려 보냈다 |
| 실제로는 | "난쟁이"는 좁은 갱에 들어가던 키 작은 아이 광부 일곱이었다. 그들이 숨긴 소녀는 영주의 의붓딸이다. 사냥꾼은 용병단이었다. 일은 "광산을 비워라"였지만 소녀는 비우지 않았다 |
| 맡은 일 | 광산의 고블린을 쫓아내라 |
| 적 | **지금 광산 그대로**: 동굴 쥐, 고블린 약탈자·궁수·주술사·고참·주술 대가 |
| 보스 | **광산 감독관(지금 그대로)** |
| 기믹 | **깊을수록 고블린이 광부의 장비를 더 들고 있다** [지금 규칙: 깊은 층의 아이템, 11층·21층] |
| 끝나면 | 소녀가 말한다. "새아버지가 나를 찾고 있어요. 결혼하겠다고." |

#### 3막 — 춤추는 마을 (열두 공주의 춤)

| | |
|---|---|
| 동화에서는 | 공주 열둘이 밤마다 몰래 춤추러 가 구두가 해졌다. 퇴역 병사가 투명 망토를 쓰고 뒤를 밟아 비밀을 밝혔다 |
| 실제로는 | 마을 사람들이 멈추지 못하고 춤추는 병(춤 역병. 실제로 1374년 라인강 일대, 1518년 스트라스부르에 있었다)이 돌았다. 영주가 판 곰팡이 핀 곡식 탓이다. 투명 망토는 없었다. 용병단의 도적이 발소리를 죽였을 뿐이다 |
| 맡은 일 | 춤추는 마을을 조용히 시켜라 |
| 적 | 영주가 먼저 산 **다른 용병단**(창병, 석궁병), 그들이 부리는 사냥개. 춤추는 마을 사람은 적으로 나오지 않는다 |
| 보스 | 그 용병단의 대장 |
| 기믹 | **멈추지 않는 음악: 적이 빨라진다** [지금 규칙: 지역 속성 swift, 적 쿨다운 −8%] |
| 끝나면 | 그 용병단의 대장: "우리도 같은 영주한테 고용됐지. 다른 일로." **영주가 일마다 다른 용병단을 썼다** |

#### 4막 — 잠든 성 (잠자는 숲속의 공주)

| | |
|---|---|
| 동화에서는 | 백 년 동안 잠든 성을 가시덤불이 덮었고, 왕자가 덤불을 헤치고 들어가 입맞춤으로 공주를 깨웠다 |
| 실제로는 | 흑사병 때 영주가 성문을 밖에서 잠가 안의 사람들을 가두었다. 성은 덤불에 덮였고 안에는 망자가 돌아다닌다. 탑 꼭대기에 살아남은 아가씨 하나가 그날을 보았다. 아가씨를 업고 나온 것은 용병단의 전사였다. 입맞춤은 없었다 |
| 맡은 일 | 잠든 성의 문을 열어라 |
| 적 | 망자(**지금의 스켈레톤 호위 그림**), 쥐 떼, 덤불 |
| 보스 | 덤불에 감긴 성주의 망령 |
| 기믹 | **가시덤불: 적이 가시를 두른다.** 근접 무기로 치면 피해를 되받는다. 그래서 활과 마법이 빛난다 [지금 규칙: 적의 아이템에 가시] |
| 끝나면 | 문의 자물쇠에 **영주의 문장**. 아가씨: "그날 문을 잠근 사람이 푸른 깃발을 달고 있었어요." |

#### 5막 — 푸른 수염의 성 (푸른 수염)

| | |
|---|---|
| 동화에서는 | 아내가 열지 말라던 방을 열자 앞선 아내들이 있었다. 열쇠에 묻은 피는 지워지지 않았다. 그때 아내의 오빠 둘이 말을 달려와 푸른 수염을 쓰러뜨렸다(페로판에서 두 오빠는 용기병과 머스킷병) |
| 실제로는 | 영주는 땅을 가진 여자와 결혼해서는 없앴다. 여섯이 사라졌다. 일곱째 신부가 2막의 의붓딸이다. 금지된 방에는 지금까지의 증거(곡식 장부, 성문 열쇠, 모병 명부)와 여섯 개의 면사포가 있다(고어 없이). 오빠 둘이 아니라 용병단이 그를 쓰러뜨린다 |
| 맡은 일 | 결혼식 날까지 모두 마쳐라 |
| 적 | 영주의 친위대 |
| 보스 | **푸른 수염.** 전쟁 영웅 출신의 거구, 시퍼런 수염 |
| 기믹 | **세 번 바뀌는 영주.** HP 75·50·25%마다 앞선 아내의 이름을 하나씩 부르며 무기를 바꾼다 [지금 규칙: 보스의 페이즈] |
| (선택) | **피 묻은 열쇠**: 성 안에 "금지된 방" 노드가 있다. 들어가면 큰 보상과 함께 저주(피로)를 받는다 [새 규칙: 새 노드 종류. 이벤트 노드는 Slice E 이후의 후보] |
| 끝나면 | 결말(§5) |

### 게임 전체의 기믹

| 기믹 | 무엇 | 규칙 |
|---|---|---|
| 결혼식까지 100일 | 100일이 기한이다. 넘기면 결혼식 밤에 성으로 쳐들어간다(강제 최종 결전) | [지금 규칙] 100일과 강제 결전. 로비 언덕의 성에 결혼식 깃발과 등불이 날마다 느는 것은 보이는 것만 바뀐다(선택, 목업 먼저) |
| 성문의 세리 | 원정에서 주운 물건은 돌아오면 영주의 세리가 "영주의 몫"으로 거둔다. 클리어하면 남은 은화를 수수료를 떼고 금으로 바꿔 준다 | [지금 규칙] 아이템이 사라짐, 클리어하면 금. 이야기는 그 까닭이다 |
| 그 땅의 은화 | 지역 코인은 던전마다 다른 동전이다 | [지금 규칙] 지역 코인. 이름과 그림은 지역을 만들 때(Architecture/09 Deferred) |
| 유품 | 이름이 새겨진 물건은 세리도 거두지 못한다 | 유물의 후보(유물은 아직 설계 전) |
| 연대기 | 인트로에서 시작 로스터의 이름이 적힌다. 용병이 죽으면 그 이름에 줄이 그어진다. 결말에서 여백에 다시 나온다 | 화면만(저장은 그대로. 이름은 지금의 전사자 목록에서 읽는다) |
| 「기록」과 「동화」 | 던전을 처음 깨면 두 쪽이 나란히 열린다. 왼쪽은 실제로 있었던 일, 오른쪽은 동화로 전해진 문장 | 화면만 |
| 영주의 성의 해금 | 던전이 다섯이 되면 "앞의 넷을 한 번씩 깨면 열린다" | [새 규칙] 지금 규칙은 "광산 N번 클리어"다. 지역이 늘 때 정한다 |

## 5. 결말

**이기면**
1. 푸른 수염이 쓰러진다. 금지된 방이 마을에 열리고, 일곱째 신부가 걸어 나온다.
2. 야코프가 연대기의 마지막 장을 쓴다. 이번 런에서 죽은 용병과 살아남은 용병의 이름이다.
3. 마지막 장면: 훗날의 그림책. "그때 아내의 오빠 둘이 말을 달려와…" 그 옆 여백에 손글씨가 있다. **"오빠들이 아니었다. 우리였다."** 그 아래에 이름들이 있다.

**지면**

| 까닭 | 결말 |
|---|---|
| 결혼식 밤의 결전에서 짐 | 결혼식은 치러졌다. 훗날의 동화는 이렇게 끝난다. "그 뒤로 영주는 일곱째 아내와 오래오래 행복하게 살았답니다." |
| 사망 한도 | 영주는 계약을 끊고 다른 용병단을 샀다. 우리의 기록은 거기서 끊긴다 |
| 용병단 전멸 | 야코프는 혼자 남아 마지막 장에 이름을 적었다. 그 책은 남지 않았다 |

## 6. 쉬운 인트로 「세 푼과 백 일」 (약 55초)

한 장면에 한 가지만 말한다. 차례는 **우리는 누구 → 무슨 일 → 일의 목록 → 이 일이 동화가 된다 → 우리가 적는다 → 시작**이다.

| # | 시간 | 화면 | 글 (한국어) | 글 (영어 초안) | 소리 |
|---|---|---|---|---|---|
| 1 | 0:00–0:10 | 비 오는 전쟁터. 줄 선 용병들. 한 손바닥에 동전 세 닢이 떨어진다 | 전쟁이 끝났다. / 우리는 열두 해를 싸우고 세 푼을 받았다. | The war was over. / Twelve years of fighting, and we were paid three pennies. | 빗소리, 동전 소리 |
| 2 | 0:10–0:20 | 진흙투성이 장터. 모병꾼이 북을 친다. 뒤에 푸른 깃발 | (모병꾼) 영주님이 용병을 구하신다! 일은 다섯 가지, 기한은 백 일! / 영주도 우리 같은 용병 출신이라 했다. 그래서 믿었다. | (Recruiter) His lordship is hiring sellswords! Five jobs, one hundred days! / They said the lord had been a sellsword like us. So we trusted him. | 모병 북 |

- 처음 대본(24 §2, 약 80초)에서 빠진 것: 세 동화를 고쳐 쓰는 몽타주(예는 하나로), "동화는 거짓말이다" 선언, "백 년 뒤", 모병꾼의 이름, 서명란의 X 표. 빠진 것은 게임 안에서 천천히 나온다(던전마다 「기록」과 「동화」).
- 그림은 5장이다(전쟁터의 해산, 장터와 모병꾼, 양피지, 그림책 한 쪽, 가죽 장부). 약 $0.15이고 요청할 때 그린다.
- 숨기는 것: 영주가 푸른 수염이라는 것(복선은 푸른 깃발과 "결혼식 날"뿐), 조항 다섯이 모두 영주의 죄라는 것.

## 7. 던전이 둘뿐인 동안

지금 게임에는 던전이 둘(광산, 심연)이다. 이야기를 먼저 넣는다면 이렇게 한다.

| 지금 | 이야기에서 | 바꾸는 것 |
|---|---|---|
| 버려진 광산 | **2막 일곱 광부의 광산** | 이름과 이야기 글만. 적·보스·수치는 그대로 |
| 심연 | **5막 푸른 수염의 성** | 이름, 보스·친위대·배경 그림(약 $0.3, 요청할 때). 수치는 그대로 |

- 계약서는 조항 둘로 시작한다("광산을 비울 것", "결혼식 날까지 마칠 것"). 지역이 생길 때마다 영주가 조항을 하나씩 더 보낸다. 이야기로도 자연스럽다("영주는 일을 하나씩 더 맡겼다").
- 스켈레톤 호위 그림은 4막(잠든 성)을 만들 때 다시 쓴다.

## 8. 판정할 것 (권장안은 굵게)

1. 이 설명과 구성(§1~§5)을 D의 기준으로: **승인** / 고칠 곳을 지정.
