2026-10-23 사용자: "새규칙으로하고 아이템의 효과를 조정하자(너무 강한 것은 지우거나 조정) / 출혈도 1초에 1개씩 소멸 / 최대 체력을 올리는 아이템 추가, 방어구 방어력 추가로 더 줄 수 있게".

## 2. 측정 (저장소 밖 복사본, 시드 1~3)

| 묶음 | 광산 클리어 / 죽음 / 붕괴 | 균형형 / 안전형 |
|---|---|---|
| 지금 (가속 1%만) | 67.3% / 0.38 / 33.6% | 92.8 / 97.6 |
| 새 규칙만 | 17.6 / 1.07 / 24.5 | 37.6 / — |
| **새 규칙 + 화상·출혈·재생 아이템의 중첩 절반** | 55.6 / 0.54 / 42.0 | 88.2 / 95.1 |
| 위 + 얼음 플라스크 경직 1,200 → 800 ms | 58.2 / 0.49 / 43.4 | 88.6 |
| 위 + 방어구 보호막 ×1.5 | **61.6 / 0.44 / 44.7** | **91.1** |

| 셋 모두 | 70.8 / 0.34 / 46.9 | 93.7 |

- **중첩 절반의 까닭**
  - 1중첩의 피해·회복이 0.27 → 1로 약 3.7배다. 한 번 건 N중첩의 총량은 1 + 2 + … + N이다.
  - 그래서 중첩을 절반으로 하면 옛 총량과 거의 같다. 예: 옛 2중첩은 0.81, 새 1중첩은 1. 옛 3성(8중첩)은 9.72, 새 3성(4중첩)은 10.
  - 거는 양이 1초 감쇠보다 덜 빨라져 끝없이 쌓이는 일도 줄어든다.
- 광산의 띠는 클리어 50~65%, 죽음 0.3~0.4, 붕괴 30~50%다. 런은 여전히 띠 위다(43단계 2차가 군주 HP로 맞춘다).

## 4. 최대 체력 아이템 (새 효과)

| 안 | 방식 | 장단 |
|---|---|---|
| **가** | **전투 시작에 최대 체력 +N, 그만큼 HP도 채움.** 그 전투 동안만이고, 끝나면 HP는 원래 최대를 넘지 않게 자른다 | 방어구(전투 시작에 보호막)와 같은 틀이라 엔진 비용이 작다. 보호막과 달리 회복으로 다시 채워지고 출혈도 받는다 |
| 나 | 보드에 있는 동안 원정 내내 최대 체력 +N(디아블로의 장비처럼) | 직관적이다. 대신 보드가 바뀔 때마다 최대 체력을 다시 셈해야 한다(놓기·빼기·합치기·조합, 저장의 최대 체력, 화면의 HP 막대) |

- 권장 출발값(가): 방어구와 같은 자리(`Armor`, 발동 `BattleStart`, 요구 스탯은 체력)에 둘을 둔다.
  - **가죽 허리띠**(1×2, 최대 체력 +4, 체력 3, 값 12)
  - **수호자의 목걸이**(1×1, 최대 체력 +2.5, 체력 5, 값 14)
  - 단계가 곱한다. 상점과 일반 드랍의 가중치는 8이다.
- 이름·크기·값은 출발값이고 시뮬로 정한다. 아이콘은 그림 라운드(요청 때)이고, 그 전에는 이름 Placeholder다.

## 5. 방어구가 방어력을 더 주게

| 안 | 내용 | 측정 |
|---|---|---|
| **가** | **방어구 여덟의 보호막 ×1.5**(철 갑옷 5.45 → 8.18 등) | 위 표: 광산 58.2 → 61.6%, 죽음 0.49 → 0.44 |
| 나 | 방어구 ×2 | 광산 60.8%(얼음 플라스크 그대로 위) |
| 다 | 방어구에 "N초마다 보호막"을 더함(쿨다운 방어구) | 재지 않음. 새 열과 엔진 비용 |
| 라 | 새 자리(장화·장갑) | 재지 않음. 그림과 자리 규칙이 필요 |

## 7. 판정과 구현 (2026-10-23)

사용자: "1. 아이템 및 포션 / 2. 절반 / 3. 0.8초 / 4. 그대로 / 5. 값 올림 / 6. 전투 시작시에 최대 체력, 현재 체력은 비율로 올라감(최대 체력이 올라간 만큼), 다만 최대 체력 아이템을 장착/해제 하면서 현재 체력을 올리는 버그는 방지 / 7. 1.5배 / 8. 바뀜 / 9. 권고안 수행". 【확정】은 02 §4·§5, 판정 표는 00 "Design/35의 판정"이다.

- 판정 6의 읽기: 전투가 끝날 때 체력을 같은 비율로 되돌린다. 오른 최대가 그 전투에만 있으니 장착·해제나 전투를 반복해도 체력이 늘지 않는다. "비율"은 비율을 유지하는 것(20/30에 +4면 22.67/34)으로 읽었다.
- 판정 5의 폭은 권장안이다. 하나씩 빼기를 다시 재고 두 번 올렸다(시드 1~3).
  - 깃발·로브·허리띠는 값을 더 올려도 "빼면 광산 +3%p"가 그대로였다. 방어구 칸의 장비 피로와 명중의 상한(95%) 때문으로 본다. 그래서 적당한 값에서 멈췄다(사후 검토).
