## 5. 새 시뮬 결과 — Slice A (2026-09-30, 일괄 승인 범위)

옛 도구가 없어 규칙을 다시 정하고(02~04) 시뮬을 새로 만들었다. 아래 수치는 새 규칙과 새 시뮬의 결과다.
위 1~4절의 옛 결론과 직접 비교할 수 없다.

### 도구와 방법
- `Tools/Sim` (C#). 게임과 같은 Domain 코드, 같은 생성 JSON을 쓴다.
- 짧은 던전 `abandoned_mine`(속성 swift, 전투 3층 + 보스)을 파티마다 3,000회. 시드 1에서 파생.
- 정책: `none`(입력 없음), `balanced`(HP 30% 이하나 DoG에 포션, 사망 발생 또는 2명 DoG에 포션 없음이면 후퇴),
  `safe`(HP 50% 이하에 포션, 사망 발생 또는 유예가 끝난 DoG 1명에 포션 없음이면 후퇴).
- 재현: `dotnet run --project Tools/Sim -- expedition --party knight,bishop,spellblade --policy balanced --runs 3000 --seed 1`

### 관찰
- 【확정 — 시뮬】 포션과 후퇴가 사망을 크게 줄인다. 기본 파티에서 입력이 없으면 원정당 1.24명, balanced 정책이면 0.22명이 죽는다.
- 【확정 — 시뮬】 bishop이 있는 파티가 뚜렷하게 낫다. 회복과 보호막이 DoG를 늦추고 끊는다. bishop이 없는 파티는 12~47%에 머문다.
- 【확정 — 시뮬】 위험은 보스에 몰려 있다. 기본 파티는 1~3층에서 DoG에 들어가지 않고, 보스전에서 전투당 1.65번 들어간다.
  죽는 것은 거의 전열 용병이다.
- 【확정 — 시뮬】 **절벽: 화상의 쌓이는 속도가 줄어드는 속도를 넘는 지점.** 화상은 틱마다 1씩 줄어든다. 적의 화상 부여가
  1초에 1중첩을 넘으면(예: 3.5초마다 4중첩) 화상이 끝없이 쌓인다. 조정 중의 한 설정에서 적 주술사의 화상을 3중첩에서 4중첩으로
  올리자 기본 파티의 클리어율이 100%에서 88%로, 입력 없는 경우의 사망 수가 0.2에서 1.0으로 뛰었다. 그 사이에 중간이 없다.
  적의 화상은 이 선 아래로 둔다.
  지역 속성 swift가 적의 쿨다운을 줄이므로 이 선을 넘기는 방향으로 작용한다.
- 【확정 — 시뮬】 전투 시간은 평균 22초, 보스 31초다. 폭풍(45초)까지 가는 전투는 0.3%다.
- 【해석】 옛 기록의 "전열 전사 필수"와 같은 방향의 결과다. 전열이 없는 파티(bishop, archmage, spellblade)는 35%다.
